# MuRata 料号选项表（PartNumber）与冒烟仿真实证

日期：2026-11-05　环境：ADS 2027（`E:\ADS\Programfile\ADS2027`），工作区 `E:\ADS\Work_AI\DAB_ATX_wrk`

## 1. 卡点是什么

村田库的元件不是"填数值"的模型：`LQW18AN_00` 的 12 个参数全是 STRING，其中
`PartNumber` 必须从原厂选项表 `LQW18AN_00_list_opt` 里**选**，不能自填 `"18nH"`。
旧实现只把 string 参数当普通文本写进 `p.value`，所以：

- `params={"PartNumber": "18nH"}` 会被静默写进去，网表里留下一个不存在的 form，仿真才报错；
- `inspect_component_model` 本来就看不到选项表，模型也没法"按 18nH 反查料号"。

## 2. 实机取到的机制（ADS 2027 SDK，不是推断）

`PartNumber.formset.name = "LQW18AN_00_list_opt"`，共 101 个 form（100 个料号 + `NULL`）：

| form 名（=料号） | label | net_format | display_format |
| --- | --- | --- | --- |
| `NULL` | `NULL` | `NULL` | `NULL` |
| `LQW18AN2N2D00` | `1:LQW18AN2N2D00, Wound, 2.2[nH], +/-0.5[nH], 700[mA], 50[MHz]-20[GHz]:1` | `1` | `LQW18AN2N2D00` |
| `LQW18AN3N6C00` | `2:LQW18AN3N6C00, Wound, 3.6[nH], +/-0.2[nH], 850[mA], 50[MHz]-20[GHz]:2` | `2` | `LQW18AN3N6C00` |

要点：

1. **label 就是选型表**：序号、料号、Type、Value、Tolerance、RatedCurrent、FreqRange。
2. **网表值不是料号**，是 `net_format` 里的序号（`PartNumber=36`）；`display_format` 才是料号。
3. 选定料号后，`Type/Value/Tolerance/RatedCurrent/FreqRange` 由 AEL 回调
   `muRataLibWeb_L_paramType_L_cb` **自动派生**，它们是 `PARM_NOT_NETLISTED`，不该手填。
4. `is_discrete_value` 对本版本没有判别力（`PartNumber` 是 `False`）。判定"选型参数"用
   「formset 里存在常量 form」：`StdFormSet` 只有自由文本 `StringForm`，不会误判。
5. `smt_pad_layer` 这类 formset 的 `StringFormWithAELCallbacks` 的 `net_format` 是 `%d`
   模板，**不能当网表值用**；枚举时一律跳过含 `%` 的模板。

## 3. 改动清单

### 3.1 `addon/ads_agent/model_ops.py`

- 新增「离散选项表」段落（`_enumerate_choices` / `_param_selection` / `_match_choice`
  / `_parse_choice_label` / `_parse_quantity` / `_unit_family` / `_choice_suggestions` 等）：
  把 formset 枚举成 `{form, part_number, value, tolerance, rated_current, freq_range, netlist_value}`，
  物理量按 SI 前缀归一（`2.2[nH]` → `2.2e-9`），并按 formset 名做进程内缓存。
- `_check_parameters`：string 参数的取值**真的去选项表核对**；写法不同（写料号而不是 form 名）
  给 warning，值不存在给 problems + 最近料号 + "用 search_model_parts 反查"的提示；
  返回 `choice_checked`。
- `_model_param_entries` / `_model_def_info`：参数表新增 `formset`，并给
  `selector_params`、`selection`、`choices`（含 `truncated` 与说明），预算用完的参数写
  `{"skipped": true, "note": ...}`，不假装没有选项表。
- `list_library_components` / `inspect_component_model`：新增 `include_choices`、
  `choices_limit`、`max_choice_params`；inspector 附 `usage`（怎么选、用哪个工具、仿真注意）。
- **新工具 `search_model_parts`**：按料号/关键字/数值（`18nH`）/容差/额定电流/频率反查真实料号，
  默认只扫工作区已挂接的原厂库（`_is_attached_vendor_lib`，路径在 `<workspace>/ads_agent_models`
  下），支持 `include_builtin=true` 扩到全部库；带时间预算与 `stopped_early`。
- `validate_model_import`：附加 `selector_params`；`unverified` 文案按 `choice_checked`
  说明"料号必须在选项内"，不再笼统说"参数未校验"。

### 3.2 `addon/ads_agent/ads_ops.py`

### 3.4 冒烟仿真夹具（本轮同时修掉的两个真 bug）

- **夹具短接**：端口原来固定摆在 `(-8, -4i)`，P1 的走线会穿过位于 (0,0) 的引脚 1，
  保存时 ADS 按几何重提取网络 → `LQW18AN_00:X1 N__1 N__1`（两引脚同网）。
  现在按**真实引脚坐标**左右摆端口（`pin.snap_point`，偏移 100 mil），并在保存前自检
  "DUT 是否有两个引脚同网络"，有就直接判失败，不再生成假数据。
- **数据集判定**：数据集的**块名**由控制器决定（实测 `SP1.SP`），块内列才是 `S[1,1]`。
  旧代码拿 `S(1,1)` 当块名 → 仿真成功也被判失败。现在先按真实块名取，列名同时认
  `S[1,1]` 与 `S(1,1)`，并新增 NaN/Inf、常数曲线、端口应有曲线数（`ports²`）检查。
- **deferred 残留**：后台仿真回填后没清 `deferred`，`_apply_smoke` 仍按"执行中"写
  `not_checked`，于是"明明跑完却永远 verified=false"。现在回填时清标记，并清掉
  "仿真仍在执行"的占位结论。

## 4. 实机验收证据（2026-11-05，toolserver 8763）

- `get_vendor_model_info(muRataLibWeb_L:LQW18AN_00, include_choices=true)`：
  `selector_params` 给出 `PartNumber → LQW18AN_00_list_opt, count=100, selectable=99,
  free_text_allowed=false`，`choices` 带料号/数值/容差/电流/频率。

  `LQW18AN18NG00`（±2%，550 mA，netlist=36）、`LQW18AN18NJ00`（±5%，550 mA，netlist=37），

  `"LQW18AN18NG00"` 与网表序号 `"36"` 都能正确落成 `PartNumber=36`，回调自动填好
  Type/Value/Tolerance/RatedCurrent/FreqRange。
- `validate_model_import(..., parameters={"PartNumber": "LQW18AN18NG00"},
  run_smoke_sim=true, require_smoke_sim=true)`：
  `ok=true, verified=true, overall=simulated, stages.simulated=pass`，

  里读到块 `SP1.SP` 的 S 曲线。

## 5. 推荐用法

1. `list_vendor_models` 找库/cell → `get_vendor_model_info(include_choices=true)` 看
   `selector_params` 与 `choices`。
2. 只有物理要求（如 18 nH ±5%，≥500 mA）时用 `search_model_parts` 反查真实料号，交用户确认。
3. `build_schematic` 只写 `params={"PartNumber": "LQW18AN18NG00"}`；Value/Tolerance/
   RatedCurrent/Size 等派生字段不要写。
4. `validate_model_import(run_smoke_sim=true)` 才是"可用"的判据；`inspect_component_model`
   只证明定义可读。

## 6. 限制与注意

- 只读原厂库，任何改动都发生在工作区副本/临时 cell 上。
- 本轮用 MuRata L/C 实机验证；其它套件只要也是"常量 form 选项表"，走同一套逻辑，
  但**没有逐个实机验证**，不许据此声称其它厂商已验证。
- 选项表缓存按 formset 名做键，导入新库后如需立刻看到新料号用 `refresh=true`。
- 改了 `backend/model_tools.py` / `backend/tools.py` / `backend/agent.py` 后，**后端进程需要重启**
  才能让 LLM 端看到 `search_model_parts` 与新提示词（ADS 侧 toolserver 会按 mtime 热重载）。
