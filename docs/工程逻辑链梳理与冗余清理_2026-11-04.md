## 一、逻辑链（自顶向下）

### 1. 入口层（ADS 插件端，addon/ads_agent/）
- `panel.py` — Qt 聊天面板（宿主在 ADS GUI 进程内）。ChatWorker 发 SSE/HTTP 到后端；停止链路：`_post_cancel()` 主动关读取 socket + `/chat/cancel` 回执区分"排队已取消/仍在执行"；会话保存走 500ms 合并写（`_save_projects`/`flush_projects`）；顶栏绿色按键常驻显示当前版本（v1.3.6）。
- `backend_launcher.py` / `pathbridge.py` — 启动并定位后端进程与仓库路径（`paths.py:PLUGIN_VERSION` 是版本号唯一来源）。
- `toolserver.py` — ADS 进程内的工具执行服务：原子有界入队、活跃上限、pump 软时间预算、GUI 心跳（/health 里 `gui_heartbeat_age_ms`）、JobContext 取消语义（queued→跳过不执行，running→如实标记）；`/cancel` 对执行中仿真直接踢 `ads_ops.cancel_sim_process()`。
- `ads_ops.py`（约 8900 行）— 全部 ADS 实操：DISPATCH 表（workspace/design/schematic/simulation/netlist/audit/run_python…）；`_simulate` 自管 hpeesofsim 子进程（预算 + 取消 + `_terminate_sim_tree`，`_SimStopped` 区分"我们终止的"与崩溃）；auto 布局 + R-01~R-29 走线/标注/尺度门禁（规则表在 `schematic_rules.py`，几何在 `geometry_policy.py`）；run_python 在 GUI 主线程执行（仅短脚本，长计算禁止）。
- 附件侧：`model_attachments.py`（ZIP 模型）、`pdf_worker.py`（PDF 手册解析，字体门禁）。

### 2. 服务层（backend/，独立进程）
- `server.py` — HTTP/SSE 编排：/chat、/chat/cancel（Turn.cancel + `propagate_cancel` → compute/ADS 双路取消 + cancel_requested SSE）、/models/*、/datasheets/parse、/health（含 compute 视图，不为统计创建管理器）。
- `agent.py` — LLM Agent 循环：SYSTEM_PROMPT（RF 设计规则/门禁）、Turn 作业登记（register/mark/clear，终态才移除）、`_run_tool_call` 派发前生成 job_id 贯穿全链；`_get_compute_manager` 懒单例。
- `tools.py` — 工具注册与路由：`TOOLS` schema（含 create/list/open_workspace）、`LOCAL_TOOLS`（后端本地：run_compute、datasheet/device 模型工具）、`timeout_for`、`call()` → toolserver /execute（带 job_id/client_id），503→Busy、超时→Timeout（作业真实状态仍可查）。
- 计算隔离（2026-10-30 架构决策）：`compute_manager.py` + `compute_worker.py` — 长计算（优化/拟合/大搜索）走后端子进程，绝不进 ADS GUI 主线程；状态机 queued→running→succeeded|failed|cancelled|timed_out，partial≠成功。
- 数据/模型：`pdf_extract.py`、`datasheet_models.py`、`datasheet_curves.py`、`device_library.py`、`device_models.py`、`model_*`（导入验证/门禁/编排）、`spice_schematic.py`（保守 SPICE 子集→Circuit IR，不完整来源会阻断建图/仿真工具）。

### 3. 数据流闭环
聊天消息 → panel → server(/chat) → agent（SYSTEM_PROMPT 注入 RF 约束 + 附件/会话上下文）→ 工具调用：
- ADS 类 → tools.call → toolserver（GUI 心跳队列）→ ads_ops DISPATCH → ADS de SDK；
- 计算类 → LOCAL_TOOLS.run_compute → compute_manager 子进程（预算/取消/回收）；
- 结果 → SSE 事件流 → panel 增量刷新 → project_store 持久化会话。
取消链：用户停止 → /chat/cancel → Turn.cancel + propagate_cancel →（compute.cancel 停止标志+宽限+终止自有 pid 树 / toolserver /cancel 排队跳过或标记）→ SSE cancelled → panel 停止等待。

### 4. 质量与发布
- `tests/run_tests.py`（CASES 登记，threading.excepthook 使后台异常计 FAIL）；当前全量基线见 task_plan 2026-11-04 段。
- `release_manifest.py` 白名单（test_packaging.py 用 AST import 闭包校验）+ `tools/build_release.py`；`check_env.py` 由 selfcheck.bat/打包引用（保留）。
