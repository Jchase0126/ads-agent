# PDF 数据手册建模入口

聊天附件支持选择、拖放或粘贴 PDF。上传到本机鉴权接口 `/datasheets/parse`，上限 32 MiB。原始 PDF 按 SHA-256 内容寻址保存到用户数据根 `datasheets/files/`，文档记录引用其 `document_id`；聊天可向配置的模型服务发送提取文本。原 PDF 不依赖上传缓存或源路径长期存在。发送后，聊天记录显示 PDF 文件卡片与解析摘要；抽取正文只进入模型上下文，不展开成可见聊天气泡。

## 当前调用链

1. 上传后获取 `document_id`（原文件 SHA-256），调用 `inspect_datasheet` 确认真实页数、解析器版本与行级可靠性；再用 `get_datasheet` 按关键词/分页读取、`read_datasheet_page` 按真实页码读取带 bbox 的行级证据。解析器是否可用由实际 worker/依赖能力决定；扫描件 OCR 或视觉读取不可用时如实标为未支持。
2. 调用 `save_datasheet_parameters` 保存型号、器件类型、参数值、单位、最小/典型/最大值类型、测试条件与原文引用。`review_parameter_set` 只能升级到 `evidence_checked`；`verify_parameter_semantics` 还核对表格与型号列、符号绑定条件、非负 Min/Max 顺序，证据不足不得升级。
3. 基础 R/L/C 或明确的无源等效器件可调用 `prepare_datasheet_model`。有源器件按证据选择原厂模型包、固定偏置数据二端口或已实现器件族的受约束拟合。当前通用等效拟合只支持 JFET 小信号拓扑；不能把它泛化到 BJT/MOSFET。
4. 拟合结果通过 `build_device_model` 生成验证电路计划。后续 `build_schematic`、`run_simulation`、`read_traces` 和 `validate_device_model` 必须走标准路径；独立网表数值检查不等于原理图验收。
5. `publish_device_model` 可将模型记录原子归档至共享模型库的 `devices/` 子目录，生成 device/model/revision 身份、不可变清单、证据引用、分项验证、端口映射及完整依赖；同内容去重，新内容保留新 revision。未验证结果只有显式允许才能以 `candidate` 发布，不能冒充已验证版本。
6. 后续对话用 `search_model_library` 按型号/厂商/能力/已验证频段检索，`get_model_revision` 查看清单；`import_device_revision` 复制依赖并在当前工作区建元件 cell；`place_device_component` 建立使用电路。仿真须随后由标准 `run_simulation` 调用，以保留可信执行记录。
7. 目前有源模型的组件计划和使用电路已实现，但 ADS 符号视图生成及“新工作区导入→放置→仿真”尚未完成真实面板验收。因此模型库 `candidate` 不应被当作可复用 ADS 符号元件或已验证模型。

## PDF 解析限制

标准库抽取器不解析字体 CMap、完整 PDF 对象树、扫描件 OCR 或曲线数据。可读英文不代表数值准确：负号、微单位等字形仍可能丢失。检测到 Identity 编码、ToUnicode、Differences 或对象流 ObjStm 时，禁止直接保存建模参数。压缩流中的映射标记同样检查。此门禁是保守检查，不是对所有 PDF 数值正确性的保证。

缺失或不可靠的参数不可通过器件常识补齐。解除拦截需要可靠的字体解析及数值验证流程，当前没有用户点击即绕过的入口。

## SMMBFJ310L 样本核验

文件：`SMMBFJ310L.pdf`，SHA-256：`113d3cb19b47f74879741cf408983f03ab89b0123f1e1beecc3bd8a2442871b8`。以下是原 PDF 页面读取和参数表图像复核的记录，不是自动保存的模型参数。

该手册共 5 页，覆盖 J309/J310 多个型号。SMMBFJ310L 为 N 沟道 JFET，不能采用基础 RLC 模板代替。

| 参数 | SMMBFJ310L 手册值 | 条件与解释 |
|---|---|---|
| IDSS | 24–60 mA | VDS=10 V，VGS=0；未给典型值 |
| VGS(off) | 表中 −2.0 与 −6.5 V 两界限 | VDS=10 V，ID=1 nA；按数值排序为 −6.5 至 −2.0 V |
| 正向跨导模值 | 8–18 mS | VDS=10 V，ID=10 mA，f=1 kHz |
| 输入电容 Ciss | 最大 5 pF | VGS=−10 V，VDS=0，f=1 MHz |
| 反向传输电容 Crss | 最大 2.5 pF | 同上；不能直接视作标称 Cgd |

第 4 页包含固定偏置下的 S/Y 参数幅度和相位曲线。曲线数字化可支持该偏置附近的近似小信号模型，但需要提取、拟合与误差验证；不能据此声称获得任意偏置下的非线性模型。手册没有直接提供 SPICE `.MODEL`。

实际样本解析中，标准库提取会漏掉部分负号和微单位。该文件包含 ObjStm，已验证 `parameter_extraction_safe=false`，通用参数存档被正确阻止。随后按用户要求开展该样本的专门流程：页面复核参数表，直接提取第 4 页矢量曲线，生成固定偏置公共栅 S2P 模型；两套模型均已在 ADS 2027 实际仿真。详细数据与限制见 `output/datasheet/SMMBFJ310L/模型验证报告.md`。此专门流程固定来源 SHA，未解除通用解析门禁，也未建立非线性 JFET 模型。
