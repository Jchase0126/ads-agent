## 二、阶段一逐条落实

### 1. 三端拓扑：公共端封装支路（P0）

`build_device_model` 现在对 g/s/d **统一**建链：`外部端 → R → L → 内部 FET 引脚`。
公共端的外部端就是参考地（GROUND 引脚），内部公共端**不再直接接地**。
支持 `common_gate` / `common_source` / `common_drain`（新增），公共端基变换由
`_config_basis` 统一给出（`Y_cs = Mᵀ Y_cfg M`；三种配置变换到公共源的结果与
3×3 不定导纳矩阵子矩阵一致，误差 ~1e-18）。物理封装脚号与 ADS 符号脚号仍是
两张独立表。

历史缺陷的实机证据（2026-10-13 的 ADS 网表）：

```
FET:DEVICE_CORE  0 N__2 N__3 ...            ← 公共端（gate）直接接 0
R:PKG_R_S ... L:PKG_L_S ... R:PKG_R_D ... L:PKG_L_D ...
（没有任何 PKG_R_G / PKG_L_G）
```

修复后（本轮实机生成的等效网表）：

```
FET:DEVICE_CORE N__2 N__3 N__4 ...
R:PKG_R_G 0 N__8 R=2.61221112662 Ohm
L:PKG_L_G N__8 N__2 L=0.527056342707 nH
R:PKG_R_S ... L:PKG_L_S ... R:PKG_R_D ... L:PKG_L_D ...
```

### 2. 非零公共端 R/L 回归（逐支路核对，不只数实例）

新增独立网表求解器 `device_models.solve_plan_y2p(plan, configuration, freqs)`：
解析建图计划的 R/L/FET/TermG/GROUND 实例与连线，做节点消元求二端口 Y，再与
`circuit_y2p` 的解析正演比较。**破坏实验**（离线可复现）：

| 计划 | 与解析正演最大偏差 |
| --- | --- |
| 三端全支路（修复后） | 3.99e-16 |
| 缺公共端（gate）支路 | **3.30e-3 S**（被判定 fail） |
| 缺漏极（drain）支路 | 1.86e-3 S（被判定 fail） |

`tests/test_pdf_modeling.py::test_package_topology_builds_common_branch_and_solver_catches_omission`
逐端检查支路、检查公共端不得直连地、并断言破坏实验必须被检出。

### 3. 验证结果四分账

`validate_device_model` 返回 `sub_results`：`import_consistency` /
`numeric_equivalence` / `datasheet_accuracy` / `scope_coverage`，每个子结果含
`state`（pass/fail/not_evaluated）、`evaluated`、`metrics`、`threshold`（含
`origin`）、`scope`、`reasons`。另加独立的 `provenance`。

### 4. 分维度容差

```
S（无量纲）：max_complex_abs 1e-4，max_nrmse 1e-4
Y（西门子）：max_complex_abs 1e-6，max_nrmse 1e-4
建图计划拓扑：max_complex_abs 1e-9
```
逐元素判据 = `complex_rmse ≤ max(绝对下限, 相对容差 × 该量纲峰值)`；
S 与 Y **不共用**同一个阈值（共用会被工具拒绝并提示分维度给阈值）。

### 5. 无阈值 → 不 validated

* 无手册精度阈值：`datasheet_accuracy.state = not_evaluated`，
  整体 verdict = **`validation_incomplete`**（`verdict_reasons` 说明缺哪个阈值）；
* 任何必要检查失败 → `validation_failed`；缺必要检查 → `validation_incomplete`；
* `ok=true` 只表示工具执行成功，与 `validated` 严格分开（提示词、工具 schema、
  验收脚本、界面文案已同步）。

### 6. 数据集来源绑定

`provenance` 记录并校验：工作区、库/cell/view、网表指纹（`design_version.netlist_sha`）、
数据集 SHA-256（>128MB 不计算并如实标注）、文件大小/mtime、数据集频段 vs 建图扫描、
建图指纹（模型重建后旧结论作废）。**只凭 `dataset_path` 不再能关联模型**；
`simulation` 证据由后端从 `run_simulation` 的真实返回值注入（`_with_simulation_evidence`），
不接受模型自填。

### 7. 频率轴与数据完整性

`_read_traces_strict` 拒绝：缺表达式、NaN/Inf、空数据、x/y 异长、频点 <2、
频率轴非严格单调（重复/乱序）、real/imag 频率轴不一致、各参数频率轴不一致
（禁止静默截断/混频）。6 类异常输入均有负例测试。

### 8. 交集内比较

`_overlap_mask` + `_interp_on_overlap`：只在仿真网格与曲线频段的**交集**内插值，
越界部分标 `extrapolated` / 无交集标 `not_evaluated`；**已删除** `np.interp`
两端常数填充的旧路径。相位按环绕角差 `angle(a·conj(b))` 计算；低幅值点
（S<1e-3、Y<1e-6 S）不参与相位统计并报告被排除点数与 `phase_state`。

### 9. 负例测试（用户点名的五类全部覆盖）

| 错误数据集 | `test_negative_wrong_dataset_provenance`（库/cell 不符、无来源证据、缺网表指纹、频段不符 4 例） | `validation_failed` |

## 三、阶段二逐条落实

1. **表格证据**：参数项新增 `table`（`row_id` / `column_id` / `header_path` /
   `model_column` / `min_typ_max` / `footnote` / `test_conditions_region` /
   `shared_range_quote`），落盘并参与门禁；引用中出现数字只算 `evidence_checked`。
2. **结构化条件绑定原文**：`structured_condition_evidence` 扫描原文
   "数值+单位"对并换算 SI 后比对。原文 10 V / 10 mA 下写 99 V / 99 A：
   **保存期即拒绝**；保存后篡改再复核也失败（文档复现已修复）。
3. **归属与兼容**：曲线按 `document_id` / 配置 / 端口顺序 / z0 / 条件逐项核对，
   不兼容直接拒绝拼接；型号必须在手册文本中有证据；变换（Y→S）显式记录方法与前后样例。
4. **幅相配对**：同一 (键, 分量) 重复拒绝、单位必须一致、相位单位与记录顺序无关、
   非法下标与矩阵前缀错配拒绝、必须完整 2×2、幅相频点必须逐点相同。
5. **曲线复核**：新工具 `review_datasheet_curves`（轴/图例/路径/偏置/端口证据 +
   preset SHA 复核），未复核曲线不能进入建模；preset 曲线保留 SHA 门禁与来源。
6. **参考阻抗**：S2P 头部改为实际 z0（`# MHz S RI R <z0>`）；只有 Y 曲线时用
   记录 z0 做 Y→S 并记录；`record_z0` 校验全部曲线 z0 一致。
