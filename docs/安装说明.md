# ADS Agent 安装说明

ADS 内置的 AI 助手插件：在 ADS 里直接聊天、自动建图、跑仿真、评估指标、
生成结果页。

> **支持 ADS 2024–2027（Windows x64）**：ADS 2027 为已实机验收基线；
> ADS 2024–2026 为**实验性适配（未实机验证）**——安装方式相同，但
> 写/建图/仿真需在 `config.ini` 的 `[compat]` 节按年份显式开启
> （如 `experimental_2025 = true`），面板标题会显示"实验性"。
> 逐功能状态见 [兼容性矩阵](兼容性矩阵.md)。

> **不需要另外安装 Python、Anaconda 或 PySide6。**
> 安装与运行都优先使用 **ADS 自带的解释器**（`<ADS安装目录>\tools\python\python.exe`），
> 界面所需的 Qt 绑定（PySide6 / PySide2）也是 ADS 自己提供的。

---

## 一、三步装好

### 1. 安装

双击 **`安装 ADS Agent.bat`**。

脚本会：

1. 自动找 ADS 安装（按 环境变量 → 上次安装记录 → Windows 卸载表 → 常见安装位置 的顺序）；
   找到多个时会让你用 `--ads-dir` 指定；要装到多个版本，
   重复传 `--ads-dir`（每个版本一次）或使用 `--all` —— 各版本分别注册，互不覆盖；
2. 自动挑一个能用的解释器（ADS 自带优先，本机完全没有 Python 也能装）；
3. 把插件注册写进 `<ADS安装目录>\config\eesof_addons.xml`（写入前自动备份）；
4. 准备好用户数据目录 `%LOCALAPPDATA%\ADSAgent`，首次运行会从干净模板生成配置文件。

看不到"双击"这一层也行，命令行是一样的：

```
安装 ADS Agent.bat
e:\ADS\Programfile\ADS2027\tools\python\python.exe install_addon.py
```

### 2. 重启 ADS 2027

注册信息在 ADS 启动时读取，**必须重启**才生效。

重启后右侧会出现 Agent 面板；没有的话从菜单 **Tools ▸ ADS Agent ▸ 打开对话面板…** 打开。

### 3. 在面板里配置 API（不用改配置文件）

1. 点面板顶部 **⚙ 设置**；
2. 选服务商预设（DeepSeek / 智谱 GLM / OpenAI / Ollama），填入 API Key；
3. 点 **检测** —— 会验证连通性并自动拉取可用模型清单；
4. 在模型清单里勾选要用的那个，直接开聊。

## 二、数据放在哪

**程序文件**和**用户数据**是分开的，这是升级不丢配置、卸载不误删的前提：

| 类型 | 位置 | 卸载时 |
|---|---|---|
| 程序文件 | `%LOCALAPPDATA%\Programs\ADSAgent`（默认） | 可选删除 |
| 配置（含 API Key 与回环令牌） | `%LOCALAPPDATA%\ADSAgent\config.ini` | **默认保留** |
| 会话记录 | `%LOCALAPPDATA%\ADSAgent\projects.json`（另有 `.bak`） | **默认保留** |
| 设计任务 / 结果页 | `%LOCALAPPDATA%\ADSAgent\design_jobs\` | **默认保留** |
| 日志 | `%LOCALAPPDATA%\ADSAgent\logs\` | **默认保留** |
| ADS 注册记录 | `<ADS安装目录>\config\eesof_addons.xml` 里的一条 | 会被移除 |

从旧版本（数据放在代码目录旁边的那种）升级时，旧数据会被**复制**到新位置，
旧文件**原样保留不删除**；如果新位置已经有一份有效数据，旧内容不会覆盖它。

---

## 三、升级

直接再跑一次 **`安装 ADS Agent.bat`** 就行。它会：

* 更新注册到的程序目录（路径变了只改那一条，不加第二条）；
* 记录新的插件版本号；
* **保留** API 设置、会话、设计任务。

装完不需要手动清理任何东西。担心出问题可以先备份
`%LOCALAPPDATA%\ADSAgent` 整个目录。

> 同一个 ADS 上如果之前装过别的 ADS Agent，建议先卸载那一个再装，
> 否则两个后端会抢同一个 8760 端口。本插件启动时会检测这种情况并在日志里提示。

---

## 四、卸载

双击 **`卸载 ADS Agent.bat`**。

默认行为：

* 移除 ADS 注册里的本插件那一条（其它插件一条都不动）；
* 询问是否删除程序文件目录；
* **保留** `%LOCALAPPDATA%\ADSAgent` 里的全部用户数据。

要连数据一起删，必须显式说明：

```
install_addon.py --remove --purge-data
```

卸载完同样要**重启 ADS** 才生效。

---

## 五、环境自检

双击 **`环境自检.bat`**，或：

```
check_env.py
```

它会依次报告：使用的解释器、ADS 目录、程序/数据目录是否分离、安装版本、
配置与令牌状态（两端是否一致）、ADS 注册状态与路径是否一致、后端与工具服务的
**实例身份校验结果**、是否检测到重复实例。

## 六、常见问题

**面板提示「后端未启动」**
插件会自动拉起后端。若持续失败，先看 `环境自检.bat` 的输出，再看
`%LOCALAPPDATA%\ADSAgent\logs\backend.log`。最常见的原因是另一个 ADS Agent
后端占着 8760 端口 —— 自检里的「后端多开检测」会直接指出来。

**提示「端口上的服务无法确认归属」**
端口上坐着别的东西（另一个安装的后端 / 旧版本后端 / 完全无关的程序）。
本插件**不会**因为 `/health` 返回 200 就认它。处理办法：结束多余进程，
或在 `config.ini` 的 `[backend] port` 换一个端口。

**提示「回环令牌不匹配」**
两端读的不是同一个配置文件。跑一次 `环境自检.bat`，它会告诉你要不要
`python backend/ads_auth.py --rotate` 重新生成令牌。

**ADS 装在 Program Files 里，安装时报权限不足**
用「以管理员身份运行」打开安装脚本；或者试用
`install_addon.py --user-level`（该路径根据 ADS 的配置搜索顺序推断，
**未经实机重启验证**，装完请务必重启 ADS 确认菜单出现）。

**没有找到 ADS**
用 `--ads-dir` 显式指定：

```
install_addon.py --ads-dir "E:\ADS\Programfile\ADS2027"
install_addon.py --detect          # 先看看探测到了什么
```

**想换安装位置 / 只想就地注册（不开硬盘上的副本）**

```
install_addon.py --mode deploy --install-dir "D:\Tools\ADSAgent"   # 复制到指定目录
install_addon.py --mode inplace                                    # 就地注册当前目录
```

## 七、命令行参数一览

```
install_addon.py                      安装（幂等，可重复执行）
install_addon.py --remove             卸载注册
install_addon.py --status             查询注册状态
install_addon.py --detect             只列出探测到的 ADS 候选
install_addon.py --ads-dir <目录>      显式指定 ADS 安装目录
install_addon.py --install-dir <目录>  程序文件安装目录
install_addon.py --mode auto|inplace|deploy
install_addon.py --accept-default      探测到多个 ADS 时直接用第一个
install_addon.py --no-scan             不做磁盘扫描（更快）
install_addon.py --remove-files        卸载时一并删除程序文件目录
install_addon.py --purge-data          卸载时一并删除用户数据（不可恢复）
install_addon.py --json                机器可读输出
```
