# 1.3.0 — RF 计算器

日期：2026-10-30

## 新增

- **RF 计算器窗口**：`Tools ▸ ADS Agent ▸ "RF 计算器…"`。
  版式参考实机 AppCAD 设计页面重新绘制：黄色传输线计算页（等轴结构图内嵌
  尺寸输入框、右列结果行、`Calculate Z0 [F4]` / `Calculate W [F3]`、
  底部 Web 条、右上 `Main Menu [F8]`）、白底偏置页（原理图 + 器件参数
  分组 + 编号操作说明 + Bias Analysis 结果表）、NoiseCalc 栅格页
  （Set Number of Stages + 逐级列头 + Stage Data/Stage Analysis 分区 +
  System Parameters / System Analysis / IM 底盒 + 状态 LED），外加
  Outlook 式分组侧栏（传输线 / 有源电路 / 信号与系统 / 工具，图标矢量
  自绘）。全部结构图为 QPainter 矢量绘制，未使用任何原软件位图。
  **1:1 复刻**：以实机 AppCAD 4.00 截图为唯一基准逐页像素测量（顶点坐标、
  渐变端色、绘制顺序与遮挡关系、尺寸线端点、输入框 bbox；规格与放大裁剪
  存 `appcad_shots/spec_v2/` 与 `spec_v3/`），29 页示意图全部按原图几何重画。
  共 29 页：微带、带状线、同轴（圆/方）、平行双线、**线过地板**、CPW、
  板线、**RFIC 电压偏置**、**RFIC 电流偏置**、**大/小信号检波器**、
  **BJT 固定基极偏置**、BJT 分压偏置、FET 自偏/分压、放大器效率、
  **S 参数（Smith 图）**、**集总元件巴伦**、反射工具、级联噪声、
  混频器杂散、互调、**器件热设计**、**SPCS**、**标准值计算**、
  **工程常数**、**复数运算**、基片库。侧栏分五组（传输线 / 有源电路 /
  信号与系统 / 可靠性 / 工程工具）。窗口无模式、关闭即隐藏（保留状态），
  拿不到 ADS 主窗口时退化为独立窗口。PySide2/6 双绑定（经 qtcompat）。
- **线过地板 Wire Over Groundplane 页**：引擎镜像法
  Z0=(60/√εr)·acosh(2h/d)（2h/d≫1 退化为教科书式 60/√εr·ln(4h/d)），
  `Calculate Z0 [F4]` 分析 + `Calculate H [F3]` 综合（同式反解 h）。
- **BJT 固定基极偏置页**（AppCAD 20 页原生 RB 单电阻拓扑）：
  Ib=(Vcc−VBE)/RB、Ic=β·Ib、Vce=Vcc−Ic·RC，稳定性系数 S=β+1；
  Vce≤0.3V 时告警饱和（线性假设失效）。原分压偏置页保留并存，
  页内注明两者拓扑差异。
- **计算引擎 `backend/rfcalc.py`**：纯函数、纯标准库、SI 单位进出；
  非法输入返回 `{"ok": False, "error": ...}`，永不抛异常；公式超适用域
  带中文警告。公式出处（Hammerstad–Jensen 1980、Cohn 1955、Wen 1969、
  Simons 2001、Friis 1944、Frankel 1962、镜像法等）写进每个函数
  docstring。
- 窗口与后端共享同一引擎实现（addon 经 pathbridge 按路径加载
  `backend/rfcalc.py`），无重复逻辑；为后续 LLM 工具接入预留（函数即
  工具实现，本版只发布 UI）。

## 法律边界（重要）

Avago/Broadcom AppCAD 是专有免费软件。本功能为按公开文献公式的
**clean-room 重实现**：未反编译、未翻译、未复制原软件任何代码、数据或
文案。数值口径差异与逐项对拍清单见
[RF 计算器与对拍清单](../docs/RF计算器与对拍清单.md)。

## 已知边界

- AppCAD 的巴伦、检波器、反射计、RFIC 偏置、S 参数查看器、杂散电平估计
  本版未实现，后续版本补齐；"线过地板"传输线页因引擎暂无对应模型未复刻。
- AppCAD 界面中引擎未建模的部分保留版式并灰显注明：NoiseCalc 的温度校正
  行（Noise Temp 显示引擎 tsys_k 口径）、dNF/dT 与 dG/dT 列、级联 IM 盒；
  偏置页的 min/typ/max 器件参数列、Design Rules 与 Stability Analysis 表；
  混频杂散页以 RF/LO 端点合并多次调用近似实机的扫频热力图（结果表为
  本版增补，实机无内嵌表）。
- 带状线/板线/CPW 闭式在极端几何（w/b>10、d/b>1、h<(S+2G)/4 等）会拒绝
  或警告，界面有提示。
- 实机（ADS 2027 + AppCAD 并装）数值验收待用户执行；离线回归已全绿。
