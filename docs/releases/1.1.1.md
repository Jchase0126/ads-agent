# ADS Agent 1.1.1

本次补丁更新优化供应商与模型管理，并保留 1.1.0 的 ADS 2024–2027 兼容机制。

## 更新内容

- 供应商侧栏显示自定义名称、模型数量，支持搜索；窄窗口自动切换为紧凑布局。
- 一个 API 连接可添加、同步并勾选多个模型，地址和密钥由该供应商共用。
- 点击对话输入栏的模型名称，向上展开菜单，选择同一供应商下的其他模型。
- 修复已有供应商连接参数载入，密钥默认隐藏，可点击眼睛查看；新增供应商不继承旧密钥。
- 优化添加供应商入口，修复添加模型按钮文字裁切，删除重复说明，调整主题和间距。
- 同步结果页的响应式排版，数据点窗口继承主题并保持只读，避免窄窗口按钮裁切。

## 安装与升级

下载本 Release 的 `ADSAgent-1.1.1.zip`，关闭 ADS 后解压并运行安装入口。
配置与会话保留在原用户数据目录，数据格式版本仍为 1。
`SHA256SUMS.txt` 提供安装包校验值；GitHub 自动生成的 Source code ZIP 是源码包。

## 验证与限制

- 发布前完整离线回归：39 个测试文件全部通过，0 失败、0 超时、0 跳过。
