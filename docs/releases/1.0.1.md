# ADS Agent 1.0.1

面向 Windows 和 Keysight PathWave ADS 2027 的 AI 助手插件。

## 下载与安装

下载 `ADSAgent-1.0.1.zip`，完整解压后运行 `安装 ADS Agent.bat`，然后重启 ADS。
ZIP 内提供安装、卸载、自检入口和中文说明。
GitHub 自动生成的 `Source code` 压缩包是开发源码，安装请使用上面的 ADSAgent ZIP。

需要自行安装并授权的 ADS 2027；本包不包含 ADS、Python 或 Qt 的二进制。
API 配置在插件面板的设置中填写。

## 本次更新

- 程序与用户数据分离，用户数据保存在 `%LOCALAPPDATA%\ADSAgent`。
- ADS 安装位置识别、独立安装目录部署及 XML 注册备份和回滚。
- 旧数据迁移、升级保留配置与会话、卸载默认保留用户数据。
- 后端和工具服务实例身份校验，检测端口占用与实例冲突。
- 按白名单构建分发包，排除密钥、会话、日志与仿真产物。
- 修复流式工具调用收集后未返回的问题。
- 新增 GitHub 离线测试、构建及版本标签发布流程。

## 验证与限制

本地离线验证见 [验证记录](../验证记录-1.0.1.md)，GitHub Actions 结果见仓库对应提交。
现有交付记录报告本机 ADS 2027 实机验收通过；本次 GitHub 发布准备未重新运行 ADS 实机验收。
跨机器安装、其他 ADS 版本和多 ADS 实例并行操作尚未完成验收。
当前提供 ZIP 加 BAT 安装入口，尚未提供图形 EXE/MSI 安装程序。

升级前关闭 ADS，再解压新版本并运行安装入口；用户数据默认保留。
本项目尚未选择开源许可证，源码可见性不代表额外的复制或再分发授权。
