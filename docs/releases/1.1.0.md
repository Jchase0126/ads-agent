# 1.1.0 发布说明

## 这一版做什么

**ADS 2024–2027 跨版本适配（Windows x64）**。1.0.x 只支持 ADS 2027；
这一版把"版本差异"集中进一个兼容层，让插件在其它版本上至少能
安全地做只读工作，写入能力则按证据与用户显式选择逐个开放。

**结论先行（准确表述）**：

- ADS 2027 —— 已实机验收基线（1.0.1 实机验收 + 本版全部离线回归）。
- **ADS 2024–2026 —— 实验性适配：已完成官方文档研究与离线验证，
  未实机验证。**没有 ADS 2024/2025/2026 实机环境，本版**不做任何
  "实机通过"的表述**。
- 不支持 32 位 Windows（ADS 2024+ 官方仅提供 64 位产品）。

## 交付内容

1. **集中兼容层**
   - `backend/adscompat.py`：版本档案（官方证据编码）+ 门禁策略。
     版本识别以 **Windows 卸载表为权威**（实机核实：ADS 2027 →
     DisplayVersion 6.5.0.0；`buildInfo.xml` 只含架构，不含版本）。
   - `addon/ads_agent/capability.py`：运行时能力检测（只读探测，
     supported / unavailable / unknown 三态）+ 工具门禁（fail-closed）。
   - `addon/ads_agent/qtcompat.py`：PySide6 / PySide2 绑定适配
     （2026 官方发行说明：PySide2 已升级为 PySide6；2024/2025 为 PySide2）。
2. **安全降级**：读/聊天按能力检测开放；写/建图/仿真/任意代码按年份
   显式开启（config.ini `[compat] experimental_<年份> = true`），
   界面持续显示"实验性·未实机验证"；未知版本仅只读。
3. **多版本安装管理**：`install_addon.py --ads-dir`（可重复）/ `--all`；
   各版本分别注册、程序目录按版本隔离、卸载只动选定版本；
   `install_state.json` 的 `ads_installs` 表兼容迁移 1.0.x 单值记录。
4. **跨版本实例冲突识别**：同一份安装被两个 ADS 版本同时使用时，
   端口占用会报 `cross_version_conflict`，不会误连。
5. **文档**：[版本证据报告](../版本证据报告.md)（官方来源逐条列证据与未知项）、
   [兼容性矩阵](../兼容性矩阵.md)（版本 × 功能，含证据/状态/默认开关）。
6. **CI**：Python 3.12 + 3.14 双矩阵（3.12=ADS 2025 官方随附版本；
   3.14=ADS 2027 实机核实 3.14.6）。

## 验证（严格分层）

| 层 | 结果 |
|---|---|
| 官方文档确认 | 平台矩阵 / Python 3.12（2025）/ PySide2→PySide6（2026）/ automation API 更名等，见版本证据报告 |
| Python / Qt 离线验证 | 既有本机记录 38/38 通过，含 Qt 层；GitHub 3.12/3.14 矩阵结果以 Actions 对应提交为准 |
| 模拟接口验证 | 假 keysight 模块树 / 假 PySide 绑定的契约测试（test_capability / test_qtcompat） |
| ADS 2027 实机验证 | 1.0.1 已有实机验收；本版在 2027 实机补充核实：注册表识别、Python 3.14.6、PySide6 6.10.3、buildInfo.xml 仅架构；`tools/real_machine_check.py` 全部环境探测 OK |
| ADS 2024–2026 实机验证 | **未执行**（无环境）。验收步骤见兼容性矩阵第六节与 `tools/real_machine_check.py` |

## 升级与兼容性

- 1.0.x 用户重跑安装即升级：用户数据（配置/会话/设计任务）保留；
  旧 `install_state.json` 的单值 `ads_dir` 自动迁入多安装登记表。
- 协议版本未变（PROTOCOL_VERSION=1），新版后端可对接 1.0.1 插件
  （旧插件无 compat 快照 → 工具列表不过滤，行为与 1.0.1 相同）。
- 本版本以 `v1.1.0` 标签发布为预发布版；1.0.1 的标签与安装包保持原样未动。

## 已知限制

见 [兼容性矩阵](../兼容性矩阵.md) 第五节。要点：2024 插件加载方式未证实
（Beta 期）；2026 DE Python 版本号官方未公开（不做映射）；在线 Python API
参考未能访问，接口签名核对依赖未来实机验收。
