# ADS Agent 1.2.0 — 模型库工作流

1.2.0 增加原厂模型包的上传、跨工作区备份、检索和 ADS 导入流程，并把模型依赖纳入仿真结果复用判断。版本继续包含 1.1.2 的启动与健康检查修复，以及 ADS 2024–2027 兼容代码。

## 模型库

- 在聊天窗口上传 ZIP 后，插件将压缩包保存在当前工作区，并检查包结构。上传本身不会解压或改写 ADS 工程。
- 用户明确要求导入后，Agent 才会解压模型包、索引器件，并将 Design Kit 挂接到当前 ADS 工作区。
- 完成挂接后可按厂商、料号或模型名称检索，并读取模型信息或执行导入验证。
- 原始 ZIP 的备份保存在持久化配置所指向的 `libraries` 文件夹中。首次导入时默认为工作区同级的 `libraries`；配置会跨工作区保存。已有相同内容按 SHA-256 复用。
- 从共享目录调用模型时，Agent 会把所选模型包复制到当前工作区并导入；每次操作使用 ADS 当前打开的工作区作为固定目标。

## 仿真依赖

仿真记录网表和模型文件的内容指纹。若引用模型发生变化、缺失或无法完整解析，系统不会复用旧仿真结果，会要求重新仿真或报告依赖状态。

## 验证边界

离线测试覆盖上传、归档、共享检索、工作区绑定、解压和导入编排、模型依赖门禁以及发布白名单。对具体厂商 Design Kit 的完整 ADS 仿真仍须在目标 ADS 版本与实际工作区中验收；本版本说明不把离线流程测试表述为厂商模型实机仿真通过。

## 升级

关闭 ADS，下载 `ADSAgent-1.2.0.zip` 并运行安装入口。配置、会话和设计任务按既有升级流程保留。用户首次导入模型时会创建或复用已配置的共享 `libraries` 目录。
