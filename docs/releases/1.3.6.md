# 1.3.6 — 对话式新建/打开工作区 + 顶栏更新入口改版 + 上下文用量环

发布日期：2026-11-04

## 背景

用户三轮反馈汇总：

1. 希望**通过对话直接新建或打开 ADS 工作区**——此前 agent 只有
   `open_workspace` / `get_workspace_info`，遇到"新建一个工作区"只能口述
   手动步骤；已知工作区名字但没给路径时也无法自动找到。
2. 顶栏绿色更新按钮希望**在没有新版本时显示当前版本号**（如 `v1.3.5`），
   而不是消失或常绿；随后进一步反馈：默认应是**黑色扁平文字**、只在检测到
   GitHub 新版本时才亮起**绿色圆角胶囊**，且窄面板下品牌字「ADS Agent」
   不能消失。
3. 用量环希望能看到**输入 / 输出 / 缓存命中**的完整构成，特别是流式响应下
   的缓存命中统计。

## 对话式新建 / 打开工作区（新工具）

- **`create_workspace`**：「新建一个叫 X 的工作区」即可创建目录、按需建立
  首个元件库（`de.create_new_library`）并打开。失败返回 `created=false` 与
  `reason`（`exists` / `invalid_name` / `invalid_path` / `needs_force` /
  `sdk_unsupported`），已存在目录**绝不覆盖、绝不删除**，所有拒绝路径
  零磁盘副作用。
- **`list_workspaces`**：按名称/路径片段过滤候选工作区。只扫已知根目录的
  1–2 层（单根上限 2000 条目、总预算 3 秒，超限 `truncated=true` 并说明），
  禁止 `os.walk` 全盘扫描。
- **`open_workspace` 增强**：`path` 支持完整目录 / 父目录 / 名称片段；
  多候选返回 `ambiguous` + `candidates`（最多 10 条，按最近使用排序），
  零命中 `not_found`，目录缺 `lib.defs` 为 `invalid_path`，当前已打开其它
  工作区且用户未确认切换时返回 `needs_force`——切换会丢弃未保存修改，
  用户确认后才传 `force=true`。
- **最近工作区记录**：数据根目录新增 `recent_workspaces.json`
  （原子写 `os.replace`、去重、上限 20 条），同时继续写
  `last_workspace.txt` 保持旧入口兼容。
- **根目录解析**：`root` 参数 → 环境变量 `ADS_AGENT_WORKSPACE_ROOT` →
  最近工作区父目录 → `%LOCALAPPDATA%\ADSAgent\workspaces`；亦可在
  `config.ini [agent] workspace_root` 配置默认根。
- **能力门禁**：两个新工具已登记 `capability.TOOL_REQUIREMENTS` 与
  `backend/adscompat.py` 读写分类（`list_workspaces` 只读、
  `create_workspace` 写类），实验性年份版本不再被误挡或漏门禁。
- 提示词同步改写：「请在 ADS 中手动打开 Workspace」不再是首选建议；
  模型必须先列候选、不得替用户挑选、`needs_force` 必须先确认。

## 顶栏更新入口改版（行为变更）

- **双态视觉**：更新入口常驻标题行——平时是与品牌字同色的**黑色扁平文字**，
  显示当前版本号（如 `v1.3.5`，跟随深浅主题，透明背景）；**只有检测到
  GitHub 有新版本**才切换为绿色圆角胶囊「一键更新 vX.Y.Z」（#22C55E、
  四周带弧形、白粗体）。
- **点击语义分层**：有可用更新＝下载 → SHA-256 校验 → 覆盖安装 → 自动重启
  后端（沿用 1.3.5 链路）；没有可用更新（初始 / 已是最新 / 检查失败）＝
  立即**重新检查更新**，不再是「点了没反应」的死按钮；下载期间禁用并显示
  「正在下载更新…」。
- **prepare 复检自动复位**：点击「一键更新」后端复检发现其实已是最新时，
  按钮自动复位为当前版本号并可点，不再永久卡在下载态。
- **品牌字常驻 + 布局锁宽**：`ADS Agent` 标题在任何面板宽度都可见
  （空间不足时省略号为 `AD…`，不再消失）；更新键最小宽度锁定 `sizeHint`，
  任何状态下更新键与「模型设置」按钮都不被裁字；窄面板（<400px）设置键
  临时收窄 8px、绿色胶囊只显示新版本号（完整说明在 tooltip）。
- **状态与异常**：已是最新时优先显示检查结果的 `current_version`，更新完成
  显示 `applied_version`；tooltip 与 `setAccessibleName` 同步；取不到本地
  版本号时文案回退「检查更新」（不硬编码版本号）；新逻辑一律 never-raise。

## 上下文用量环补全（输入/输出/缓存命中）

- **流式 usage 真正到手**：所有流式请求带 `stream_options.include_usage`
  （网关回 400 时自动去掉重试，绝不让整轮对话因此失败）；流内分块到达的
  `usage` 由「整体替换」改为**逐键 + 嵌套 details 合并**，DeepSeek 与
  OpenAI/GLM/StepFun 形状都能拿到 `prompt_tokens_details.cached_tokens`。
- **缓存用量规范化**：`backend/model_context.py` 新增 `normalize_reported()`
  （兼容 `prompt_cache_hit_tokens` / `prompt_cache_miss_tokens` /
  `prompt_tokens_details.cached_tokens`，脏数据一律 None、绝不抛异常），
  `usage()` 增补缓存命中字段（估算路径全为 None，不用 0 冒充）。
- **用量环详情浮层**：主环语义不变（80%/95% 才变色），点击/悬浮/聚焦打开
  详情浮层——分组显示「上下文 / 本回合（输入·输出·缓存命中及命中率·
  未命中·推理）/ 本次会话（请求次数·缓存命中率）」，缺失字段整段省略，
  估算值带 `≈`；每轮统计行在 `hit+miss>0` 时追加「缓存命中 62%」。

## 已知边界（诚实说明）

- 工作区三工具为**离线验证**（fake `de` + 真 HTTP 派发链路）；真实 ADS 2027
  实机上的 `create_workspace` / `create_new_library` 语义（真实库创建、
  force 切换的未保存修改丢弃提示）尚待实机验收。
- `list_workspaces` 只扫已知根目录 1–2 层：放在深层嵌套目录里的工作区
  不会被自动发现（仍可用完整路径打开）。
- 更新入口复用 1.3.5 的更新链路与安全边界（开发检出拒绝自动覆盖、
  config.ini 与日志永不被覆盖），本期未改动后端更新协议。
- 用量环的会话累计只统计接口实测 usage，重启面板清零；估算值不参与累计。

- v1.3.5 用户：顶栏黑色版本号（本版起不再常绿）→ 检测到 1.3.6 后点击绿色
  「一键更新 v1.3.6」即可自动完成下载、校验、覆盖安装与后端重启。
