# ADS Agent 1.1.2 启动热修复

修复 1.1.0 和 1.1.1 中可能导致面板打不开、工具服务未监听及健康后端被误判离线的问题。
感谢用户提供 ADS 2026 Update 1 的修复包和故障记录，帮助定位发布兼容代码的遗漏。

## 修复内容

- 修复八处 Qt 获取函数误用，恢复自动打开面板、工具服务定时器及错误对话框。
- 修复 `/health/health` 重复拼接引发的 401 和启动超时。
- 健康探测兼容服务根地址与完整 `/health` 地址。
- 缺失 ADS 目录不再误判跨版本冲突，服务身份补齐实际 ADS 目录。
- 关闭工具服务时停止定时器并释放监听端口，支持重新启动。
- 新增真实 Qt 与 HTTP 启动集成测试，保留身份、协议及令牌校验。

详细原因见源码仓库的 [故障分析](https://github.com/Jchase0126/ads-agent/blob/v1.1.2/docs/启动与健康检查故障分析.md)。

## 验证

- 完整离线回归：40 个测试文件全部通过，0 失败、0 超时、0 跳过。
- ADS 2027 自带 Python 3.14.6：真实 Qt / HTTP 启动集成测试通过。
- 当前 ADS 2027 开发面板的后端健康复用探测通过。
- ADS 2026 Update 1 的启动及只读工具结果来自用户提供的记录，本环境未重复该版本实机验收。

## 升级

下载 `ADSAgent-1.1.2.zip`，关闭 ADS 后解压并运行安装入口，再启动 ADS。
配置和会话保留，数据格式版本不变。校验文件为 `SHA256SUMS.txt`。
ADS 2024–2026 仍为实验性适配；本补丁不改变写入类工具的显式开启规则。
