## 对话建图的固定流程

1. **区分物理尺寸与原理图坐标。** `W=3.06 mm`、`L=17.3 mm` 是器件参数，不是放置坐标。先读取一个标准元件的 `bbox`；本机 ADS 标准符号通常约宽 1。相邻元件先按 3～8 个原理图单位布局。
2. **优先使用 `build_schematic`。** 一次提交元件、参数和连接。它会先备份，再保存，关闭写句柄后只读重开，核对实例、参数、VAR 值和指定引脚的网络。不要用多轮 `run_python` 边猜 API 边修改同一个设计。
3. **把网络和图形都核对。** 导线画到引脚上并不保证电气连通；连接工具还需显式绑定引脚网络。保存后核对连接两端属于同一网络，再看网表中的端口和节点。画面好看不能替代网表检查。
4. **先过仿真门禁再运行。** 核对控制器、端口、基板引用、实例数和网表生成。仿真成功后确认 `.ds` 文件存在；只有进程退出成功而数据集缺失时不能称为完成。
5. **按 ADS 数据结构读结果。** S 参数数据集顶层常见 `SP1.SP`，矩阵元素在 `S[1,1]`、`S[2,1]` 等列。用 `read_traces` 的 `dB(S(2,1))` 等表达式取曲线。结果页出现 `unknown` 时先检查表达式和单位，不要把它当作达标或未达标。
6. **同一轮避免重复仿真。** 刚得到的 `.ds` 在设计未改动时可供结果页复用；修改元件、变量或执行任意 Python 后必须重新仿真。
7. **核对用户看到的窗口。** 数据库 `open_design` 不等于 ADS 图形窗口已刷新。若窗口仍显示旧视口或旧内容，让用户关闭该编辑窗口后从 Library 树重新打开，并执行 View All。不要只凭数据库实例数就声称 GUI 已正确显示。

## 程序中的防回归措施

- `build_schematic` 对导线跨度与符号尺寸做比例检查；明显错误的千单位布局会在保存前被拦截。只有用户明确需要超长几何连线时才使用 `allow_large_geometry`。
- 对话提示词中的建图示例统一采用符号尺度，并说明 `SP1.SP` 矩阵结构。
- 同一轮对话中，设计未改动且刚完成仿真时，发布结果页复用该数据集；成功发布不会因空的 `error` 字段被误记为失败。
- 关键回归测试包括网络合并、布局尺度、VAR 落盘、S 参数曲线读取和数据集复用。

## 2026-09-25 布局美化：layout="auto" 与正交走线

用户反馈 LLM 自拟坐标的原理图"布线太丑"：分支斜线、跨链电阻斜穿全图、注释件散在四角。修复分三层：

1. **`_ortho_points`（治本兜底）**：`_wire_connection` 画线前检查端点是否共轴；不共轴按主导方向加一个 90° 拐点（横向为主先竖后横，纵向为主先横后竖）。任何坐标下都不会再画出斜线。
2. **`auto_layout_positions`（按信号流排布）**：`build_schematic(layout="auto")` 时实例可不写坐标。规则：端口(Term)间在"水平引脚边"图上的最短路径为主干，放 y=0 行从左到右；其余端口经分支脚引入的水平连通块作为分支臂，挂在锚点分支脚正下一行（行距 5）；两端都接分支脚的跨链件（隔离电阻）竖放在上下两行正中、对齐上方引入引脚的列；GROUND 落所接引脚正下方 2；VAR/MSUB 排左上、仿真控制器左下，行高按文本行数估。**关键判据**：偏离元件通轴的引脚（MTEE 第 3 脚类）只许作分支引入边，不作信号通路内部边——否则隔离电阻（两端都是分支脚）会被误认成某条端口路径的一段，把真正的 λ/4 支线挤成桥接件。引脚偏移按实测建档（MLIN/R/Term 在 origin 与 origin+(1,0)，MTEE 第 3 脚在 origin+(0.5,-0.5)），旋转用 `_rot_off`。
3. **提示词/schema**：系统提示与工具 schema 改为推荐 `layout="auto"`，LLM 不再自己编坐标；手动布局仍走尺度门禁。

布局只挪坐标不改电气：实例的 angle/params/连接保持原样，网表逐元件一致（网络名会因重建重新编号，核对按"网络成员集合"逐网比对）。Term 朝向属于例外：输出端口 R180 使射频脚朝左是布局语义的一部分，重建脚本里显式给出。两个竖放注意点：竖放元件 origin 不在行线上（以出线脚计行）；竖放 MLIN 的引脚都在通轴上，不是分支脚。

实测：Wilkinson_5G9 重建后主干 7 元件一行、ML3 竖放下分支、R1 竖放行间、唯一非共轴连线自动拐直角；顺手修复其端口接地短路（原 Term 地脚与射频脚同网 = 端口自短路，网表 `Port:PORT1 N__0 N__0`，补 GND 后 `0 N__2`），仿真 S11=-5.0/S21=-5.3/S31=-7.0 dB @5.9GHz。Wilkinson_2G4_v2 同法重排，13 网络逐网一致。旧 ADS 窗口保留旧视口，查看新布局需关闭后从 Library 树重开。

## 2026-09-28 原理图流线与就近接地

只看网络连通与“没有斜线”不足以说明布局合格。GROUND 应紧靠端口地脚；导线不得穿过元件符号或贴着符号边缘重叠，也不得与本次新增的其它导线交叉或共线重叠。自动连线先尝试直线和单拐点，受阻时沿符号外侧寻找更短的正交路径；手工指定的折点若违反这些规则则在保存前报错。此检查针对本次建图的导线与可读取的符号外框；已有旧导线及文字标注仍需在 ADS 窗口中复核。


## 2026-09-28 导线几何硬门禁 + TermG 默认端口（十五轮迭代）

用户截图点名 Wilkinson_1G7_ML 的 Riso 上下斜线。取证结论（不是猜的）：

1. **斜线根因是手工路径**：build_schematic 的连线全部经 _wire_connection
   正交门禁（当天日志里它两次正确拦截了无法布线的拓扑），但模型随后绕到
   run_python 手工 connect()/add_wire，把两个不共轴引脚直连成斜线落盘 ——
   保存后的设计里躺着 (7,-6)->(8.5,-2) 和 (7,-1)->(8.5,0) 两段斜线。
   热重载日志证明当时跑的就是新代码，与"旧 toolserver"无关。
2. **修复三层**：connect_impl/wire_impl（手工路径同一套正交+避障规则）、
   save_impl（run_python 的 save() 落盘前几何门禁）、_geometry_report
   （保存后只读复核，从磁盘读真实导线：斜段/穿符号/无引脚 T 接/异网交叉
   共线重叠；读不出顶点的 shape 如实标"未验证"）。
3. **实测坑：MLIN bbox 宽 1.0、引脚就在 bbox 边缘上** —— 从通轴引脚垂直
   下拉的 T 结线必然擦自己符号的边缘，旧的"边界可触及即违规"规则让任何
   T 结都无法布线。修复：引脚所属符号对**从该引脚出发的导线**用"只判内部"
   的宽松规则；擦别人的符号仍然拒绝。
4. **toolserver 热重载会原样保留 run_python 常驻环境 _PY_ENV** —— 旧闭包
   还是旧代码，实测旧 connect 照画斜线。修复：助手绑定抽成模块级
   install_env_helpers(env)，重载后对保留环境重绑（用户变量不丢）。注意
   toolserver.py 本身不在热重载范围，改它必须重启 ADS。
5. **TermG（ads_simulation）实测定案**：单引脚（编号 1，origin 上），
   参数 Num/Z/Noise，网表 `Port:x N 0`（第二节点是全局地）。S 参数仿真
   S11=-36dB/S21=-0.06dB（500mil 50 欧线）电学正确。作为接地参考端口的
   默认推荐；Term 保留给需独立参考端的场合，且地脚必须接
   ads_rflib:GROUND（不在 ads_simulation！），否则新的地参考门禁会拦
   —— 悬空地脚的端口仿真"能跑完"但参考开路，结果不可信（实机验证）。
6. **auto_layout 两处升级**：分支判定改"从端口沿全边 BFS，首次触达已放
   元件即锚点"（旧的连通块+出边计数会把跨链电阻吞进分量导致分支判定
   失败）；两端都接信号通路引脚的桥接件会把下锚点所在支链整体平移到
   同列（两个输出口对齐、上下引线短而直）。端口朝向在摆放前规范化
   （Term 输入 0/输出 180；TermG 相反，符号体在 origin 右侧）。
7. 实机验收：Wilkinson_1G7_RG（TermG）与 Wilkinson_1G7_RT（Term+GND）
   两变体 0 斜段、10/7 条连线全通、门禁零阻断，S 参数完全一致
   （S11=-19.33/S21=S31=-3.21/S23=-19.90 dB @1.7GHz）；无 GND 变体被
   仿真门禁精准拦截。用户截图对应的 Wilkinson_1G7_ML 已重建（自动备份），
   真实 ADS 窗口截图复核零斜线（logs/wilkinson_1g7_ml_fixed.png）。

## 2026-09-29 RLC 取值规范：优化收敛后吸附常用值

用户明确要求：RLC 取值必须取常用值。已把规范写入 agent SYSTEM_PROMPT
（backend/agent.py「RLC 取值规范」一节），要点：

1. **标准 E 系列（IEC 60063）**，同一序列跨十年适用（2.2 档 = 22pF/2.2nH/2.2k）：
   - E12（±10%）默认首选：1.0 1.2 1.5 1.8 2.2 2.7 3.3 3.9 4.7 5.6 6.8 8.2
   - E24（±5%）E12 恶化时用，追加：1.1 1.3 1.6 2.0 2.4 3.0 3.6 4.3 5.1 6.2 7.5 9.1
   - E6（±20%）：1.0 1.5 2.2 3.3 4.7 6.8（大容值电解/普通陶瓷）
   - E96（±1%）基本只用于精密电阻，电容电感极少
2. **射频件实际商品档与理想 E 系列有出入，取值按商品档**：
   - 高 Q 电容（Murata GJM/ATC 0402 系，约 0.2~20pF）：10pF 以下按 **0.1pF
     步进**（不是 E24；0.5pF 以下有 0.05pF 档），公差 ±0.05/±0.1/±0.25pF；
     10pF 以上走 E12/E24。隔直/退耦取 100pF、1nF、0.01uF、0.1uF、10uF 档。
   - 射频电感（Coilcraft 0402HP/0402CS 系，1.0~220nH）：10nH 以下 E24 细档、
     以上 E12/E24 到约 100nH；**小于 1nH 不取**（商品极少，改微带短短线）。
   - 电阻：偏置/负载/隔离 E24 起步，偏置电流设置点用 E96（1%）。
3. **优化流程**：探索期连续值自由调；收敛后逐个吸附最近常用档并**重新仿真
   验证**；先粗后细（先 E12/0.1pF 档，S11 恶化超约 1dB 才退 E24）；相邻两档
   都不达标说明位敏感——两档串并联拼值、调拓扑或微带线替代。匹配网络 C/L
   吸附后必须复测；隔直/退耦/馈电电感"大到足够"即可（直接取大一档常用值）。
   微带线 W/L 不属于元件值，圆整到 0.01mm。汇报给吸附对照：
   优化值 → 取用值 → 复测指标。
