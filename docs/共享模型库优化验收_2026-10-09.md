# 共享模型库优化与验收

本轮按用户要求并行处理五项审查问题。程序修改位于 `D:\Antenna\ADS Agent`；当前用户共享库配置保留为 `E:\ADS\Work_AI\libraries`。

## 完成的行为

1. 发布白名单加入 `shared_models.py`，增加后端本地模块依赖完整性检查，并从解压的发行包独立加载后端。
2. 首次未配置时选择工作区同级 `libraries`，使用配置锁原子保存；以后不同父目录的工作区仍复用该位置。显式配置、环境变量优先。改变目录不会自动搬移旧资产。
3. 查询共享 ZIP 内的元件定义、料号表和厂商明确标注 PartNumber 的 HTML 表格，返回来源文件、库名、元件名和所属包。查询命中不代表已经加载或仿真通过。
4. 相同包内文件路径和内容的 ZIP，即使压缩方式、时间戳和顺序不同，也只保留一份中心备份；来源工作区原始 ZIP 保留。内容或路径改变视为不同包。损坏备份逐包报告，不阻断其他包。
5. 共享导入固定首次取得的可信工作区，复制后切换工作区会中止导入；支持复制前后取消，已有 ZIP 保留。
6. 从当前工作区挂接记录与原厂 ADSlibconfig 生成仿真映射，禁止跨工作区引用、缺失文件和冲突映射。映射写在独立仿真输出目录，只传入仿真子进程，不修改全局 ADSlibconfig 或进程环境。
7. 建图与验证测试自动添加可唯一确定的无引脚 Include；对已有原理图仿真进行只读依赖检查。枚举参数使用 ADS form 名称并调用参数变更回调，失败不冒充成功。
