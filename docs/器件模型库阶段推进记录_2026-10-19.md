# 器件模型库闭环推进记录（2026-10-19）

## 结论

已实现统一的 PDF 建模模型库身份与发布/检索/导入/放置工具；共享库根沿用 `[models] library_root`，器件资产位于 `devices/`，与现有原厂 ZIP 包清单并存。用真实 SMMBFJ310L PDF 重跑了离线解析、证据、曲线、拟合和建图计划链路，并在配置的 `E:\ADS\Work_AI\libraries` 下新增了 `candidate` 修订。

元件封装补上了两条此前缺失的实质能力：**子电路用层次 Term 暴露逻辑引脚**（不再用仿真 Port），以及**用 ADS 自带 `db_uu.create_symbol` + `experimental.generate_symbol.SymbolGenerator` 从原理图端子生成真实 symbol 视图**并在生成后只读复核引脚编号与 pin 图形。

**已在一台运行中的 ADS 2027 上完成实机闭环**（详见
[器件模型库实机验收_2026-10-19](器件模型库实机验收_2026-10-19.md)）：两个独立新建
工作区分别完成「元件建图 + symbol 生成」与「跨工作区导入 + 幂等复用 + 放置 +
真实 hpeesofsim 仿真 + 读取真实 S 参数」，两次读数逐值一致。实机暴露并修复了
9 个缺陷，其中 7 个只有真机执行才会发现（端子缺 pin、pin 图形创建实例压符号、
枚举/PointF/引脚属性名、热重载依赖缺失、子电路 define 块解析、层次实例引脚数）。

仍未完成：面板聊天 UI 端到端、`validate_device_model` 把修订推到 published、
ADS 进程重启后的复用验证、非预设手册的通用识别。共享库里两条修订仍是
candidate，不能当作可直接仿真的产品元件。

## 已落地代码

- `backend/device_library.py`
  - 统一 `device_id`（厂商+精确型号）、`model_id`（模型形态+配置+条件+参考阻抗）与不可变 `revision_id`。
  - 发布前检查 verdict；未 validated 只能显式允许并以 candidate 发布。
  - `.staging/` 完整写入后原子改名；内容重复复用，模型内容变化新建修订；写锁协调并发。
  - 清单、原始 PDF、页/曲线/参数证据引用、组件计划、S2P 依赖、分项验证报告都随修订归档；依赖及 PDF 有 SHA-256 复核。
  - 可由 revision manifest 重建损坏索引；支持型号/别名/厂商/模型类型/条件/验证状态/能力/已验证频段筛选。
  - 跨 Workspace 导入把依赖复制到目标 Workspace，登记 `revision_id → library/cell/manifest fingerprint`，同修订重复导入幂等。
  - 放置通过既有 `build_schematic` 门禁生成使用电路；仿真强制随后调用标准 `run_simulation`，避免旁路可信 simulation_id 记录。
- `backend/device_models.py`
  - 建模记录新增 task 身份与规范状态历史；验证结论随改建归档。
  - 构建 cell 名按建图规格指纹稳定派生，重复 build 不再生成随机 cell。
  - `prepare_device_model` 相同输入命中已有记录时复用原阶段，不重置拟合/建图/验证。
  - 新增三端可放置组件计划生成与结构检查：子电路用 `ads_simulation:Port` 之外的方式——
    以 `term_anchors`（`{name, number, instance, pin}`）声明逻辑引脚，公共端不在组件内接地。
- `addon/ads_agent/ads_ops.py`
  - `build_schematic` 支持 `term_anchors`：在该实例引脚所在网络上建 numbered Term
    （不新建网络、不改连通性），并把端子名从网表等价划分中排除。
  - 新增 `create_component_symbol`：只读读回原理图 numbered Terms →
    `db_uu.create_symbol` → `SymbolGenerator.generate_symbol()` → 保存 →
    只读复核 symbol 引脚编号与原理图端子一致；任一步失败整体判失败。
  - 修正引脚编号属性名：实测 `Pin.term_number`（没有 `pin_number`）。
- `addon/ads_agent/netlist_check.py`
  - `check_netlist_equivalence(..., ignore_names=)`：层次 Term 是对外引脚声明，
    不算电路元件；不排除会让同一网络块多出 `Term.x` 成员而误判不等价。
- `backend/model_tools.py`、`backend/tools.py`、`backend/agent.py`
  - 新工具：`search_model_library`、`get_model_revision`、`publish_device_model`、`import_device_revision`、`place_device_component`。
  - `create_component_symbol` 进入 ADS 端 TIMEOUTS 与 DISPATCH。
  - `import_device_revision` 在导入时生成 symbol 视图；symbol 失败则整次导入失败。
  - 导入/放置不再从后端直接启动仿真，保证可信 `simulation_id` 由标准 `run_simulation` 产生。
  - 系统提示写明型号冲突、精确版本、能力限制、candidate/published 语义及仿真来源纪律。
  - 后端本地工具未捕获异常统一转成结构化工具错误，不中断聊天。
- `backend/datasheet_models.py`
  - 条件证据从“同量纲同数值”提升为“符号+值+单位”绑定，拒绝 VGS 值冒充 VDS、IDSS 额定值冒充 ID 测试条件。
