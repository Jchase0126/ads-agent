## 1. 结论摘要

1. 【实机实测】**挂接并打开 Design Kit 库 = 已触发 boot→palette 注册**。当前 TDK 库的 10 个原生 palette 分组全部已注册、417 个元件 item 定义全部已注册（`deitem_get_visible_palette_name` / `dm_find_item_definition` 实测，见 `NL_q6b`/`NL_q3e`/`NL_q3b`）。Q3 答案 = **是**。
2. 【实机实测】存在一个未在文档列出的 AEL 查询原语 `deitem_get_visible_palette_name(window_or_context, libName, cellName)`，**返回该元件所属的 palette 分组名**（如 `TDK Chip Beads`），不存在返回 `None`。这是"程序化定位原生分类"的唯一可靠开关。
3. 【实机实测】**没有任何 API 能程序化"打开/置前" Component Palette 或 Component Library 窗口**。`keysight.ads.de.app` 全量 `dir()` 与 `_pde_app(.ui)` 全量 `dir()` 均无此能力；菜单项存在（`\Insert\Component\Component Library...`、`\View\Docking Windows\Component Palette`）但 `ActionItemDef` 不暴露 trigger/execute/qwidget，无法从受支持 API 触发。
4. 【文档记载 + 实机实测】库是否"已 boot"不能用 boot.ael 的全局 decl 判断（实测 `TDK_DK_PATH` 等在 default vocabulary 中**不存在**，但 item/palette 已注册）。判定"已加载"请改用 `dm_find_item_definition("lib:cell")` 非空 或 `deitem_get_visible_palette_name(...)` 非 `None`。
5. 【实机实测】SDK 另有一条**可写**的注册入口：`keysight.ads.de.app.create_schematic_palette/create_layout_palette`（内部即 `de_define_library_palette`，`insert_position=-2`）。当某包**没有** BOOT_AEL/palette.ael 时可作为兜底注册手段（本任务未实测其写入，属能力边界，勿在只读阶段调用）。

### Q4 `keysight.ads.de.app` 里有无"打开/显示/置前"库浏览器或 palette 的函数 【实机实测：无】
全量 `dir(app)`（`NL_q456`）中与窗口/palette 相关的公开名：

**无** `open_palette/open_browser/open_component_library/show_palette` 之类。

（`ksight.ads.de.app.menu` 的 `Menu.get_menu_actions/find_action/find_menu` 只能枚举/查找，不能执行。）

### Q6 AEL 侧可手动触发 boot 的函数 【实机实测：无专用函数】
存在性结论（`NL_q3b`/`NL_q456`）：
- **不存在**：`de_boot_design_kit`、`de_load_library`、`dk_boot`、`de_design_kit_boot`、`de_load_design_kit`、`de_boot_library`、`de_reload_library`。
- **存在**：`de_add_library_to_workspace_read_only_mode(libName,libPath)`、`de_open_library_read_only_mode(libName,libPath)`、`de_close_library`、`de_new_library`、`de_is_library_open`、`de_get_open_libraries`、`de_get_path_to_open_library`、`de_library_config_file_exists`、`de_get_library_config_file_var(libPath,varName)`、`de_refresh_library`（语义未验证）。

## 3. `de_define_library_palette` 真实语法与最小示例

### 3.1 官方语法（文档 `ael/de_define_library_palette().html`，Version Introduced ADS 2011）
```
de_define_library_palette( pal_libName, win_type, dsn_type, pal_name, pal_label, insert_position
                         [, list(libName, cellName, viewName, compLabel, compBitmap) [, ...] ] );
```
- `win_type`：`SCHEMATIC_WINDOW` | `LAYOUT_WINDOW`
- `dsn_type`：`"analogRF_net"` | `"sigproc_net"`
- `pal_name`：分组唯一名（显示在分组选择列表）
- `pal_label`：分组描述标签
- `insert_position`：`-1` 字母序、`-2` 追加末尾、`>=0` 指定位置
- 每个 item = `list(libName, cellName, viewName, compLabel, compBitmap)`；`libName` 空/NULL 时回退到 `pal_libName`；`viewName` 空则按窗口类型找默认视图；**item 是可变参数，不是 list-of-list**。
- 语义：*"loaded into the Schematic or Layout window palette bars when the library owner is opened … unloaded when closed"*。

### 3.2 DemoKit 真实调用（`examples/DesignKit/DemoKit_mmWave/de/ael/palette.ael:15`）
```ael
de_define_library_palette(DEMOKIT_MMWAVE_NAME, SCHEMATIC_WINDOW, "analogRF_net",
    "DemoKit_mmWave", "DemoKit_mmWave ", 0,
    list(DEMOKIT_MMWAVE_NAME, "demo_mmWave_FET", "",   "mmWave FET model", strcat(DEMOKIT_MMWAVE_CIRCUIT_BITMAP_DIR,"demo_mmWave_FET_BITMAP")),
    list(DEMOKIT_MMWAVE_NAME, "demo_mmWave_Res", "",   "Resistor",         strcat(...,"demo_mmWave_Res_BITMAP")),
    ... );
```
文件前置：`set_design_type(analogRFnet); if(is_pdeoa_mode()){ ... }`。

### 3.3 TDK 实际用的是另一支：`dk_define_palette_group`（`de/ael/palette.atf` 反编译字符串）
```
dk_define_palette_group( winType, dsnType, groupName, groupLabel, position,
                         item1name, item1label, item1bitmap [, item2name, item2label, item2bitmap, ...] );
```
- `winType`：`SCHEM_WIN` | `LAYOUT_WIN`（实测二者均为有效 int 常量）
- item 为**扁平三元组**（无 lib/view，隐含同库）。文档：VIntroduced ADS 2024，`ADS 2024 and newer`。
- 实测该函数在 ADS 2027 中存在且已生效。

**TDK 实测原生分组（10 个，`NL_q6b`）**：
| # | 分组名 (palette group / name) | 元件数 |
|---|---|---|
| 1 | TDK Inductors | 152 |
| 2 | TDK Multilayer Ceramic Chip Capacitors | 171 |
| 3 | TDK Common Mode Filters | 27 |
| 4 | TDK 3-Terminal Filters | 23 |
| 5 | TDK Chip Beads | 22 |
| 6 | TDK Varistors | 10 |
| 7 | TDK Pulse Transformers | 3 |
| 8 | TDK 3-Terminal Feed Through Multilayer Ceramic Capacitors | 3 |
| 9 | TDK Noise Suppression Filters | 3 |
| 10 | TDK Multilayer Chip Protectors | 2 |
| — | （未入任何分组）TDK_Common_Data | 1 |
（合计 417 cell；`palette.atf` 字符串里还能看到分组 label，如 `"TDK Pulse Transformers Design Kit"`，与分组 name 不同。）

### 3.4 最小可用"注册一个分类 + 一个元件"
AEL（等价于 DemoKit）：
```ael

de_define_library_palette("MyPkgLib", SCHEMATIC_WINDOW, "analogRF_net",
    "MyPkg Categories", "MyPkg Categories", -2,
```


## 4. 程序化打开/定位原生列表的能力边界

**能做（已实测）**
- 读库配置：`Library.get_library_cfg_var / get_raw_library_cfg_var`（BOOT_AEL、DESIGN_KIT_NAME、LIB_BROWSER_CTL…）。
- 确认"已 boot/已注册"：`dm_find_item_definition("<lib>:<cell>")` 非空，或 `deitem_get_visible_palette_name(win, lib, cell)` 非 `None`。
- **定位分类**：`deitem_get_visible_palette_name(win, lib, cell)` → 真实分组名；配合遍历 `circuit/ael` 可枚举**全部分组 + 每组成员数**（本报告 §3.3 即此法所得）。
- 保证注册发生：打开库即触发 boot（`ws.add_library` / `de_open_library_read_only_mode`）。
- 兜底注册（可写，未实测调用）：`app.create_schematic_palette / create_layout_palette`。
- 置前**已存在**的库浏览器窗口：`find_windows_by_type(WindowType.BROWSER_WINDOW)[i].show()`。

**不能做（已实测）**
- 无 API 打开/显示/置前 **Component Palette**（它是 schematic/layout 窗口的 dock，不是独立窗口类型；`WindowType` 里根本没有 palette）。
- 无 API 打开 **Component Library** 浏览器窗口（`BROWSER_WINDOW` 类型存在，但只能"找到已开着的"，开不出来）。
- 无 API 切换主窗口的 **Library View** 标签页。
- 菜单动作 `ActionItemDef` 不可程序化触发（无 trigger/execute/qwidget）。

**最接近的原生入口（按可用性排序）**
1. `find_windows_by_type(WindowType.BROWSER_WINDOW)` + `Window.show()` —— 库浏览器**已打开**时把它置前（当前实测返回空）。
2. 主窗口原生 **Library View** 标签（ADS 2011.01+ 自动展示所有已打开库的元件）；无 API，仅供人工/文档指引。
3. 菜单（需人工/仅 UI）：schematic 窗口 `\Insert\Component\Component Library...` 开库浏览器、`\View\Docking Windows\Component Palette` 显隐调色板。
4. 组件搜索：`dm_find_item_definition` 证明元件可用；`\Edit\Component\Update Component Definitions...` 为菜单项。

## 5. 对契约 `§3.1` 返回结构的修正建议

1. `boot.loaded` 的判据改为**确定性探测**（勿用 boot 全局变量）：
   `loaded = dm_find_item_definition("<lib>:<firstCell>") 非空`（或 `deitem_get_visible_palette_name` 非 None）。返回 `true|false`，拿到才算，拿不到给 `"unknown"`。
2. `boot.palette_groups[]` 建议字段（全部实测可得）：
   `{ "library": <pal_libName>, "window": "schematic|layout", "design_type": "analogRF_net",
      "name": <分组名>, "label": <groupLabel，可能与 name 不同>, "items": <int>,
      "owner": "boot|probe|sdk", "source": "de/ael/palette.atf|create_*_palette" }`
   - `name` 用 `deitem_get_visible_palette_name` 的真实返回；`items` 用枚举计数。
3. 新增 `boot.registered_components`: int（扫描 `circuit/ael` 中能 `dm_find_item_definition` 命中的 cell 数）。
4. 新增 `boot.control_files`: `{"lib_browser_ctl": {"path":"","exists":bool}, "records":[...]}`（TDK 有 `circuit/records/*.ctl/.rec`，驱动库浏览器的多层分组；见《Design Kit Components》"Control File"节）。静态检测 `native_list` 已含 `browser_ctl`，运行时也应回填。
5. `native.located` 建议补 `via` 与 `window`：
   `{"library":"","category":"","found":bool,"via":"deitem_get_visible_palette_name","window":"<窗口标题>"}`。
6. `native.palette` / `native.component_library` 的 `method` 恒为空、`opened` 恒 `false`（当前 ADS 无此 API）；`detail` 建议固定写明"仅能经菜单 `\Insert\Component\Component Library...` / `\View\Docking Windows\Component Palette` 人工打开，程序化不可"。
7. 新增顶层 `palette_api`: `{"create_schematic_palette":true,"create_layout_palette":true}`，供 `outcome=loaded_only` 时给出"可用 SDK 兜底注册"的降级路径。
8. `limits` 建议固定条目：
   - "本机 ADS 2027 未提供程序化打开 Palette / Component Library 窗口的 API（仅可定位已注册分组）"；
   - "boot 全局变量不可作为加载判据"。

## 6. 未验证项与阻塞原因

- 【未验证】`deitem_get_visible_palette_name` 的完整签名/语义：非官方文档函数，签名由报错反推为 `(window_or_design_context, libName, cellName)`；`layout` 窗口形态未验证（当前无 layout 窗口打开）。
- 【未验证】`de_refresh_library` 语义（是否触发 boot/重编 atf）。
- 【未验证】`app.create_schematic_palette` 的**写入**效果（会对 ADS 注册表产生状态变更，只读纪律下故意未调用）。
- 【未验证】菜单动作的 Qt 触发路径（`ActionItemDef` 无 qwidget，未找到受支持的 `trigger` 通道）。
- 【未验证】`de/ael/palette.ael` 源码缺失（TDK 包仅 ship 编译后的 `.atf`）；已用运行时枚举 + `strings` 反推等效分组，但与源码逐字对照不可得。
- 阻塞：以上均因"禁止改 ADS 状态/触发 UI"的只读纪律或"无源码"而未做，不影响 §1 结论。
