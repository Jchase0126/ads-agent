# 1.1.0 验证记录

日期：2026-10-07。本次为**跨版本适配**改造，验证按层严格分开；
ADS 2024–2026 **没有实机环境，相关结论只到"文档与离线验证"为止**。

## 一、官方文档确认（证据来源见 docs/版本证据报告.md）

- 平台矩阵（ADS Supported Platforms 页直接读取）：2024/2025 支持
  Win10+Win11；2026 U1.0 起仅 Win11；全系仅 64 位。
- ADS 2025 发行说明：随附 Python 3.12（DE Python 首个 production 版）。
- ADS 2026 发行说明：PySide2 → PySide6；numpy 2.2.3；RFPro/SIPro/QPro
  为 Python 3.13（子工具，不能推及 DE）。
- ADS 2024 发行说明：Python 控制台 Beta（`ads -python`）；U2.0 DDS
  Python Addon 使用 PySide2。
- ADS 2025 发行说明：automation 查询 API 更名（running_automation →
  is_pde_app）；U2.0 官方支持 threading API。

## 二、实机环境核查（本机 ADS 2027，只读）

- 注册表识别：ADS 2027 → DisplayVersion 6.5.0.0（与 1.0.1 实测 build 650
  对应）；**buildInfo.xml 只有 `<buildtype>x64</buildtype>`**（版本识别
  设计据此修正为"卸载表权威"）。
- 自带解释器：Python 3.14.6（64 位）、PySide6 6.10.3、numpy 2.3.5。
- `tools/real_machine_check.py` 环境探测：keysight.ads.de /
  db_uu.DesignMode / dataset / CircuitSimulator / PySide 绑定 全 OK
  （注意：keysight.ads.de 导入需要 HPEESOF_DIR，脚本已处理）。
- 本机另有 ADS 2022 安装：被识别为范围外 → 插件按未知版本保守降级
  （未做任何写入操作）。

## 三、离线测试（Python 3.12，本机）

- `python tests/run_tests.py`：**38/38 通过（0 失败 / 0 超时 / 0 跳过）**，
  其中新增 4 个兼容层测试：
  - test_adscompat.py（15 项）：版本识别（注册表命中 / 目录名弱证据 /
    未知 / 范围外年份）、门禁矩阵、位数判定；
  - test_capability.py（10 项）：假 keysight 接口树的三态探测、
    fail-closed、未知版本只读放行、实验开关；
  - test_qtcompat.py（8 项）：绑定选择（已加载优先/档案顺序/终身缓存/
    都没有→明确报错）、QFontDatabase 与 exec 的 Qt5/Qt6 shim；
  - test_install_multiversion.py（8 项）：双版本分别注册、登记表、
    卸载隔离（另一版本注册文件一字不动）、旧记录迁移、中文空格路径、
    deploy 按版本隔离程序目录。
- 门禁语义在测试中固化：未知版本读放行/写拒绝；实验年份读放行、
  写需 `experimental_<年份>`；2027 全放行；能力缺失一律拒绝。
