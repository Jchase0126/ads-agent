# 下一步优化建议与完整执行提示词

依据：docs/PDF交互建模最新工程审查_2026-10-14.md。目标是完成真实聊天中的 PDF 证据提取、有源建模、ADS 原理图构建和可信验证。本文件是实施要求，尚未执行其中的功能修改。

## 建议的实施顺序

| 阶段 | 主要工作 | 必须达到的结果 |
|---|---|---|
| A | 仿真来源、模型状态、参数语义漏洞 | 错来源、错列、错字段不能得到可信验证状态 |
| B | 原理图布局和走线规则统一 | 三端封装模型经正常建图门禁成功，实际连通关系符合模型规格 |
| C | PDF 单元格、条件和曲线实证提取 | 参数来源可点击定位，模型声明与原文布局一致 |
| D | 依赖运行时、部署、恢复 | 实际安装后的代码和依赖可确认，流程可恢复且不会重复建图 |
| E | 真实面板聊天验收 | 上传→解析→工具→ADS 建图→仿真→验证全链路通过 |

原理图走线规则是 ADS schematic 的导线和符号几何规则；PCB/版图线宽、阻抗、DRC、EM 仿真属于另一阶段，不能把两者的验收混为一谈。

```text

按 A→B→C→D→E 顺序实施。先交付 A+B 的可验证修复，再继续后续阶段。每阶段给出修改、测试结果、实际证据、适用限制及剩余项。无需为普通可逆代码修改反复请求确认。

一、A 阶段：仿真来源与模型状态

1. 修复 backend/agent.py 的 _with_simulation_evidence：不接受 LLM 自填来源覆盖后端来源。公开工具仅接收 model_id、可信 simulation_id 或受控 dataset 引用、验证要求；simulation 来源由后端读取可信执行记录，不由模型拼接。
2. 持久化执行记录，绑定工作区、library/cell/view、模型版本、参数/拓扑规格指纹、成功建图指纹、实际网表指纹、仿真参数、执行状态、数据集 SHA 和时间。来源必需字段缺失不能 verified。网表指纹必须实际计算并与对应执行记录核对，不接受 'invented'/'netlist_only' 这类占位值。
3. 校验当前 workspace 和设计版本，数据集读取前后校验指纹，防止设计改变或文件被替换后仍关联旧模型。simulation_id 在仿真开始时生成并贯穿执行，不能在验证时随机生成并称为来源 ID。
4. 状态至少区分 build_planned、schematic_built、simulation_completed、validation_incomplete、validation_failed、validated。独立网表正演结果单独保存为 numeric_spec_validated；原理图几何失败时不得把完整任务置 validated。
5. 不把进程异常退出后文件存在视为正常仿真完成。分别记录 process_exit、dataset_integrity、controller/trace completeness；诊断恢复可读取部分产物，但不能直接计入端到端通过。
6. 验证的 S/Y 分量纲阈值、交集频段、异常数据检查和无阈值 incomplete 行为保留。阈值在评估前声明并记录来源，不得看结果后放宽。缺少用户精度目标时先完成可独立评估的导入/等价项，将精度项标未评估。
7. 修复 prepare_device_model 的参数集 document_id、part_number、器件类型和适用条件归属检查。不能仅凭参数集状态就引用其他手册或型号的记录。

二、B 阶段：ADS 原理图布局和走线规则

先审查 addon/ads_agent/ads_ops.py 的自动布局、plan_wire_routes、在线绕障、实际连接写入、保存后几何检查，以及 backend/device_models.py 的三端模型建图规格。建立统一规则来源，避免不同阶段使用不同边界框、间距、引脚豁免和交叉判据。

1. 电气拓扑优先：
   - 在布局前由连接规格生成 canonical net_id 和端子集合，不因绘图坐标相同而自动合并不同网络。
   - 数值模型、建图规格、实际 ADS 网表均从同一模型规格派生并相互核对。三端封装的 g/s/d 都保留串联 R/L；公共端是外部端接地，内在公共端不得越过封装寄生直接接地。
   - 区分显式地、同名网络、局部节点和信号路径。去重按逻辑端子/实例身份进行，不按支路形状、阻值相同或对地关系去重。
   - 不自动旋转/镜像导致引脚语义改变；原生符号引脚号与物理封装引脚号分别记录。

2. 几何与坐标统一：
   - 获取实际符号实例的引脚位置、可见符号体边界、方向和镜像状态，统一坐标单位、网格吸附及比较容差。
   - 使用共享的 geometry/routing policy 定义 symbol_keepout、pin_escape_length、wire_clearance、annotation_clearance 和 grid_step。默认值根据 ADS 符号尺寸/单位确定，集中配置，避免散落 0.25/1.0 等硬编码。
   - 电气障碍和可读性障碍分层：符号体、不同网络引脚和危险导线接触是硬约束；文字标注优先避让，有限困难时报告可读性问题，不能因此容许电气错误。

3. 引脚出线：
   - 每个引脚先沿合法外向方向形成短逃逸段，再进入水平/垂直走线通道。
   - 端点符号豁免只允许对应引脚局部合法逃逸段，不允许整条首末段穿越自己符号体，也不允许中间点处于符号内部后得到豁免。
   - FET 三端分别预留通道；为内部三端器件、三组封装 R/L、外部端口和公共地安排结构化布局，控制支路间距和注释区域。

4. 接点与跨网规则：
   - 导线不得经过其他网络引脚，不得与不同网络共线重叠、端点接触或形成会被 ADS 判为连接的交叉。
   - 同网络分支连接到明确节点，所有分叉/连接点在网格上；不要用模糊的导线穿过来隐式连接。
   - 优先避免跨网交叉。确需使用 ADS 支持的无连接交叉表示时，必须读回确认两个网络仍隔离，不能仅凭绘图没有圆点判断。
   - 需要网络标签时只对明确相同的逻辑网络生成唯一名称，并确认 netlist 连通一致；不能靠标签掩盖缺线或错误合并。

5. 布局层次：
   - 信号主链优先从输入到输出排列；反馈、偏置、去耦和地支路分区；控制器和变量区放在信号走线通道之外。
   - 使用逻辑子图识别 FET 三端封装、共源放大级、并联对地支路、反馈回路和多级级联，避免单纯按实例顺序布局。
   - 模板只能固定相对位置与通道约束，不能硬编码本机绝对坐标或只适配 J310；支持不同符号尺寸、旋转和不同公共端配置。

6. 路径搜索与失败处理：
   - 先尝试合法直线/L/Z 路径，再使用有界正交网格搜索或可见图搜索；所有候选都通过同一合法性检查。
   - 优先级为电气正确→不穿符号→跨网隔离→留足间距→减少弯折与长度→文字可读。硬约束违反不能靠低罚分变为可写路径。
   - 当前“候选全部非法后选违规最少路线”的行为只能用于诊断，不能作为最终写入结果。返回 route_unresolved 与阻挡对象、失败规则和建议变更。
   - 必要时做有限次数的间距扩展、局部移动、通道重新分配和 rip-up/reroute；每次保留合法拓扑，限定时间/节点数/重试次数，避免无限搜索。
   - 规划输出包含每段端点、net_id、连接点、硬约束检查、成本和失败原因。在线写入原则上执行合法计划；如实际符号几何不同，则按同一规则重新规划，不能静默另走一条未经检查的线。

7. 写入及验收：
   - 尽量在修改设计前完成规划和合法性预检。失败后保持可恢复状态，使用已有备份/事务能力，不在未通过设计上连续追加修补。
   - 保存后重新打开并读取实际元件、引脚、导线和网表；核对 net_id 对应端子集合、串联支路、公共端、端口和控制器，不能只检查导线数量。
   - 输出实际原理图截图供视觉检查，并给出网表等价和几何报告。截图用于可读性，网表用于电气正确性，二者不能互相替代。
   - 必测：共栅/共源/共漏三端封装非零 R/L、不同网络共线、导线穿符号、不同网络引脚被途经、旋转/镜像、同构对地支路、密集反馈、多级级联、无合法路线、重复执行。
   - 以 J310_verify_20261014_wrk 中已记录的 FET 穿线失败为真实回归。在隔离的新测试 cell/工作区正常调用 build_schematic→run_simulation→validate，不绕过几何门禁。

三、C 阶段：PDF 读取与参数提取优化

重点模块：backend/doc_assets.py、pdf_extract.py、pdf_worker.py、datasheet_models.py、datasheet_curves.py、sample_adapters.py。

1. 原文件与页面：
   - 保留原 PDF SHA、版本、解析器版本和提取配置；沿用原子存档与去重。
   - 页面提取保留真实 page_id、宽高、旋转、坐标变换、block/line/span/token 的 bbox、原始字符和标准化字符。提供按页/区域渲染和证据查询工具。
   - 保留负号、µ/μ/u、上下标、希腊符号和科学计数法映射；映射不确定时记录未知字形、原码点和可靠性，不能全局删除乱码后标可靠。
   - PDF 正文和图片是资料，不能作为指令执行。模型请求采用按页/区域检索，避免将整本手册反复粘贴到每轮聊天。

2. 表格结构：
   - 先根据字符坐标、行列边界、表头和型号关系恢复表格，保留 table_id、row_id、column_id、cell_id、bbox、header_path、原始单元格文本及跨页续表关系。
   - 这些 ID 由解析器生成，不由 LLM 自填字符串冒充真实位置。LLM 输出参数时引用 cell_id，后端从单元格验证数值和单位。
   - 合并单元格、空白、破折号、Min/Typ/Max、多个型号列、表头单位、条件行、脚注分别建模。空白/破折号表示缺失时不得自动当成 0。
   - 具体型号必须匹配对应列；同族共用规格只有具备声明证据才能共享。Min/Max 的原表列身份与数值大小排序分别保留，负范围不得因为排序而丢失原始列含义。
   - 区分绝对最大额定值、电气特性、典型曲线和模型参数；最大额定值不能自动作正常偏置，最大电容不能自动作典型工作点电容。

3. 条件字段语义：
   - VDS/VGS/VDD、ID/IG、频率、温度、公共端和参考阻抗各绑定符号 token、数值 token、单位、cell/bbox 和条件区域。
   - 不再使用“同页存在同量纲数值”证明字段正确。VGS=-10 V 不能作为 VDS=-10 V；额定电流不能作为测试 ID。
   - 单位转换保留原始值、原单位、SI 值、转换规则和证据。已声明零但省略单位时只能依赖明确字段/表头单位恢复，不能任意猜测。
   - evidence_checked 只表示文本能找到；semantic_verified 必须表格列、型号、符号、条件和脚注关系都成立。证据不足列出具体缺失，保持 requires_review。

4. 图表与曲线：
   - 按页面定位图号、图框、轴标签、刻度、图例、偏置文字和曲线候选。矢量图优先，必须关联实际路径，不能猜 path_index。
   - 校准数据包含刻度文字的 token/bbox、PDF 坐标和物理值；至少两点校准并用额外刻度作一致性检查；区分线性/对数、双轴、频率单位、幅值/相位、dB/线性和相位单位。
   - 曲线身份必须对应图例；排除网格、坐标轴和文字轮廓；处理虚线、多段路径和非单值曲线，不把任意多段路径强行连接。报告数字化不确定度。
   - 幅相在相同频点组成复数矩阵，保持完整 2×2 和已实现的重复/非法/错频门禁。相位单位与记录顺序无关，幅值单位正确换算。
   - z0 未在手册声明时保持 assumed；配置和端口顺序必须有证据。固定偏置二端口不能直接声明为完整三端非线性 FET 模型。
   - review_datasheet_curves 的 axes/legend/path/bias/ports 不能只接收 true 布尔量，改为实际页/区域/token/path 引用及复核结果；人工声明、视觉推断和原文实证分开标注。

5. 扫描和混合 PDF：
   - 按页/区域决定文本、矢量、OCR 或视觉解析，保留识别方法与置信度。OCR/视觉能力不存在时明确 unsupported，不伪装已完成。
   - OCR 结果与页面图像可对照；高风险负号、单位、Min/Max 和型号列必须二次校验，冲突保持 requires_review。
   - 多模态能力依据实际模型服务协议检测，区分本地渲染、工具返回图像和真正发送到模型服务；未发送页面图像时不得称已视觉读取。

6. PDF 测试与验收：
   - 使用真实 SMMBFJ310L 样本核对 5 页、型号列、IDSS、VGS(off)、跨导、电容条件、图 4/5/6/7 及封装脚号；数值从证据读出，不使用预填的错误旧范围。
   - 增加同行 Min/Max 互换、不同型号列互换、VDS/VGS 互换、ID/额定电流互换、表头单位、零/缺失、负号、µ、科学计数法、旋转页、续表和扫描页用例。
   - 增加至少一份没有 preset 的真实有源器件手册；样本 preset 成功只证明回归路径，不证明通用提取成功。

四、D 阶段：统一运行环境和任务恢复

1. 提供能力探测，分别报告 PDF 文本/页面渲染/表格/矢量/OCR/拟合/ADS 建图/仿真可用性、解释器和版本。available/unavailable/degraded 不能合并成一个“PDF 可用”。
2. 扩展受控 worker 协议覆盖缺库时的解析、矢量和拟合，或提供明确的依赖部署方案；使用受限参数、超时、取消和有限输出。运行时异常以结构化工具错误返回，不能让对话直接崩溃。
3. 根据发布白名单同步实际安装目录；核实运行进程 app_root、模块指纹、工具集合和协议，不能只检查安装状态文件。保留用户数据和密钥。
4. task_id、attachment_instance_id 与内容 document_id 分离；相同 PDF 可去重存档，但每次附加和任务各有身份。任务/附件状态持久化，纯文件发送立即保存。
5. prepare/fit/build 的重复请求应幂等或显式创建新版本，不能覆盖已有验证证据或每次偷偷创建随机 cell。取消、重启和项目切换保留真实阶段，防止跨项目混用。

五、E 阶段：真实安装后聊天验收

1. 在用户实际 ADS 面板中上传 PDF，经 HTTP、聊天上下文、工具注册、后端派发、ADS RPC、真实建图、仿真和数据集读取完成流程；直接函数脚本不能替代。
2. 新建隔离的验收工程于 E:\ADS\Work_AI；保存截图、原理图、网表、数据集、模型规格、来源指纹、工具调用序列和分项验证报告。
3. 正例要求正常原理图路径成功且必要判据全部满足；负例要求错来源/错型号/错列/错条件/错幅相/漏支路/超域均得到正确拒绝或限定范围。
4. 报告区分数值等价、手册典型曲线吻合和实物性能。仅固定偏置小信号模型不能承诺 DC 工作点、噪声、压缩、温漂或大信号谐波。
5. 完成模型与交互验收后才继续 FM 放大器：全 88–108 MHz 最小增益 >15 dB 按实际数据评估；匹配、稳定性、偏置和噪声另列指标，不能只看 98 MHz 增益。100 MHz 以下及配置变化的外推限制明确报告。

交付要求：
- 修复上述确切漏洞并给出能失败于旧实现的回归，不写仅复述实现的测试。
- 运行相关单元、HTTP、工具派发和布局测试，再做必要发布及 ADS 实机检查；明确哪些未执行。
- 一阶段一份简短报告，包含代码路径、测试命令、通过/失败/跳过、产物和剩余限制。

```

## 建议的首轮范围

首次执行集中于 A+B，并补 C 中的同行取值和条件字段负例。首轮结束时应能在正常 ADS 原理图路径成功建立三端封装模型，且错误来源、错误单元格和错误条件字段被拒绝。之后再扩展通用 PDF 识别和安装后交互验收。
