## 各阶段改动与回归对应

### 第一阶段（正确性与设计操作）

1. 指标评估数据有效性（backend/design_metrics.py 重写评估边界，design_service 接入 eval_options）
   - 频段覆盖核查：两端覆盖 + 带内点数 + 带内最大间隔；覆盖不足 → pass=None（blocked_reason=band_coverage_insufficient）；显式 partial_band=True 时只评估覆盖区间并标注 eval_range、exact=False。
   - 带内读不出的点：最值类指标（min/max/flatness）→ blocked（missing_points_in_band）；mean/bandwidth 降级 exact=False 并注明。
   - value_at：目标频点超出数据范围 → blocked（out_of_range），不再就近取点判定；范围内区分 grid_hit / nearest / linear_interp，exact 相应降级；容差可配置（指标字段 tol）。
   - 单位兼容：曲线与指标单位分类（dB/dBm/V/mV/W/Ω/无量纲…），不可比 → blocked（unit_incompatible）；bandwidth_above 的 unit 是带宽单位，不参与该核对。
   - 均值口径：默认按采样点算术平均（method=sample_mean），可指定 freq_weighted（梯形权重）；结果带 method 字段。
   - 带宽口径：连续区间 + 阈值交点线性插值；端点截断标注 clipped；带内缺失点打断区间；多区间只取最宽并全量报告 intervals，绝不跨接。
   - 0 Hz 起始频段：start_hz=0 合法（旧代码 truthiness 判断已修）。
   - 横轴单位不确定（多种解释都成立）→ blocked（unit_ambiguous），不再按量级猜测后判定。
   - 数据质量：normalize_trace 输出 quality（n_raw/n_valid/n_dropped/丢弃原因/丢弃点位置/覆盖范围/最大采样间隔/重复频点/非均匀扫频/显示层降采样信息）。
   - 回归：tests/test_design_metrics.py 33 项全过（兼容）；tests/test_design_metrics_edge.py 37 项（四类已复现问题 + 长度不一致/NaN/Inf/重复频点/非均匀扫频/零频起点/阈值交点/多区间/均值口径/单位歧义）。

2. 取消与超时链路
   - turn_id：/chat 生成并回传 start 事件；POST /chat/cancel；agent.Turn 在每步前、模型响应返回后、每次工具派发前检查取消。

   - 超时分类：排队超时（未执行）/ 执行超时（504，带 job_id，作业可能仍在收尾）/ 队列已满（503 Busy）/ 网络断开 / 仿真失败，错误信息分开表述。
   - 设计任务取消：run_design(cancel_event) 在仿真前 / 仿真后 / 读取前 / 评估前检查；仿真已完成时取消保留数据集并标注"可重新评估"，绝不自动重跑。
   - 队列容量与 pump 预算：tool_queue_capacity（默认 64，满则 503）、pump_max_jobs（默认 16/次）。
   - 面板：stop() 同时发 /chat/cancel；"cancelled" 事件入册；状态栏文案如实（"已停止后续步骤（正在执行的操作会自行收尾）"）。
   - 回归：tests/test_cancel_chain.py 11 项（排队取消/执行中标记/过期跳过/容量拒绝/pump 预算/agent 三种取消时机/设计取消保留产物/异常分类）。
