## 二、官方平台矩阵（Windows / 架构）

来源：ADS Supported Platforms 页（官方标注"supported 64-bit platforms"）。
图标语义：✅=Supported，⚠=Limited Support，❌=Not Supported。

| ADS 版本 | Windows 10 | Windows 11 | Windows Server 2019/2022 | Linux | 架构 |
|---|---|---|---|---|---|
| ADS 2024（含 U1.0/U2.0/U3.0） | ✅ | ✅ | ⚠ | RHEL7/8、SLES12 ✅；其余 ❌/⚠ | **仅 64 位** |
| ADS 2025（含 U1.0/U2.0） | ✅ | ✅ | ⚠ | RHEL8/9、SLES15 ✅ | **仅 64 位** |
| ADS 2026 U0.1 | ✅ | ✅ | ⚠ | 同上 | **仅 64 位** |
| ADS 2026 U1.0 / U2.0 | ❌ | ✅ | ⚠ | 同上 | **仅 64 位** |
| ADS 2027 / U1.0 | ❌ | ✅ | ⚠ | 同上 | **仅 64 位** |

交叉印证：ADS 2026 Update 1.2 发行说明明确写着
"Support for Windows 10 has been discontinued."（与平台表一致）。

**结论（平台范围）**：
- 正式目标：Windows x64（64 位 Windows）。**不支持 32 位 Windows**（官方无 32 位产品）。
- ADS 2024/2025：Windows 10/11；ADS 2026 U1.0 起与 ADS 2027：仅 Windows 11。
- `sys.platform == "win32"` 只能判断"是 Windows"；位数判定用
  `struct.calcsize("P")*8`（解释器位数）+ `PROCESSOR_ARCHITEW6432`（WOW64 下的真实系统架构）。
  32 位启动器在 64 位系统上运行安装脚本被允许，但不宣传为"支持 32 位 Windows"。

## 三、Python / Qt 随附版本证据

| 版本 | DE（设计环境）Python | Qt/PySide 绑定 | 证据来源 |
|---|---|---|---|
| ADS 2024 | **未知**（官方未公开版本号；Python 控制台/DE Python 为 **Beta**，需 `ads -python` 启动参数） | PySide2（2024 U2.0 发行说明：DDS Python Addon "Support for PySide2 APIs"） | 2024 / 2024 U1.0 / U2.0 发行说明 |
| ADS 2025 | **3.12**（"Python version 3.12 is included in ADS installation"；DE Python 首个 **production** release） | PySide2（2025 发行说明：DDS Python Addon "using PySide2"） | 2025 发行说明 |
| ADS 2026 | **未知**（发行说明未写 DE Python 版本号；RFPro/SIPro/QuantumPro 2026 子工具各自明示 Python 3.13，不能推及 DE） | **PySide6**（2026 发行说明原文："PySide2 has been upgraded to PySide6."） | 2026 发行说明 |
| ADS 2027 | **3.14.6**（实机核实：自带解释器 `python -V`；官方发行说明未写版本号） | **PySide6 6.10.3**（实机核实：自带解释器 `importlib.metadata`；发行说明未写） | 实机（2026-10-07）+ 2027 发行说明 |

其它随附包证据：ADS 2026 发行说明"numpy … upgraded to version 2.2.3"；
实机 2027 numpy 2.3.5。

**结论（Python 语法下限）**：
- 已核实的解释器版本：3.12（2025，官方）与 3.14.6（2027，实机）。
- 代码库全量补 `from __future__ import annotations`，PEP 604 注解不再要求
  运行时 ≥3.10；除此之外未使用 match 等更新的语法特性。
- **不为 2024/2026 建立版本映射**（无证据）。离线 CI 矩阵只用有依据的
  3.12 + 3.14；对旧版环境由运行时能力检测决定，不做假设。

## 四、插件 / 自动化接口证据（按时间线）

| 版本 | 官方发行说明中的关键事实 | 对本插件的意义 |
|---|---|---|
| 2024（U1.0） | Python 控制台（Beta）：顶层 Python 菜单，需 `ads -python` 启动参数；virtualenv 支持；`dds` 模块与 DE 模块**不能**在同一 Python 进程导入（U1.0 为 Alpha DDS 模块） | 2024 上 Python 自动化整体处于 Beta；插件能否经 eesof_addons.xml 加载**未证实**（未知项） |
| 2024（U2.0） | DDS Python Addon 支持 **PySide2** API（菜单/对话框/控件）；"ads-dataset … Python libraries" 性能改进 | Qt 绑定证据：PySide2 |
| 2025 | DE Python 首个 **production** release；Python 3.12；Python Addon 支持（DDS 用 PySide2）；`keysight.ads.de.app.callbacks`；automation 模式查询 API 改名：2024 U2 及更早 `running_automation()` → 2025 起 `is_pde_app()` | 插件契约有官方记载；**两套 automation 查询 API 必须都探测** |
| 2025 U1.0 | "Actions and menus added by a Python or an AEL addon's menu generator function …"；**`de.db_uu.design` 已被吸收进 `de.db_uu`** | 插件菜单生成器契约存在；模块重组（老代码若 import 旧路径会失败） |
| 2025 U2.0 | **官方支持用户代码使用 python threading API**；sympy/QuTip 入环境 | 线程契约：2025 U2.0 起才有官方依据；2024 无 → 后台仿真默认不启用 |
| 2026 | **PySide2 → PySide6**（自定义代码需改 import）；numpy 2.2.3；Python Exporter Addon（App Manager）；`keysight.ads.dds.experimental.DDSQtWidget`（实验） | 本插件面板 import 全部收拢到 qtcompat 适配层 |
| 2026 U2.0 | Python 解释器带 PySide6-stubs；pyarrow 22.0.0；Deprecated APIs 文档节 | PySide6 延续 |
| 2027 | Python API 新增/废弃见 "Design Environment Python API documentation" Release Notes 节；**ADS MCP server**（fetch API + execute_python）；`pwdatatools` → `datatools`（旧名保留兼容）；Python PDK（Beta） | 1.0.1 实机回归基线（build 650 / DisplayVersion 6.5.0.0） |

### 安装/注册机制

- 注册文件：`<ADS>\config\eesof_addons.xml`，`<Addon Name= FilePath= Enabled= />`。
  本插件 1.0.1 在 **ADS 2027 实机**上以该文件注册并通过验收（docs/验证记录-1.0.1.md）。
- **实机核实（2026-10-07）**：版本信息的权威来源是 Windows 卸载表——
  官方安装器写 `DisplayName`（"Advanced Design System 2027" /
  "Advanced Design System 2022 Update 2"）、`DisplayVersion`（6.5.0.0 / 5.5.2.0）、
  `InstallLocation`。`buildInfo.xml` 只有 `<buildtype>x64</buildtype>`（架构），
  **不含**年份/Update/build。
- 官方 `add_user_addon` API 依赖编译进 ADS 主程序的 `_pde_app`，进程外必失败
  （2027 实测，见 addon/ads_agent/registration.py）——安装器写 XML 文件，不调 API。

| ADS 2024 自带 DE Python 版本号 | 2024 上插件语法能否运行 | 运行时能力检测；档案记 `python_official=None`；不做版本映射 |
