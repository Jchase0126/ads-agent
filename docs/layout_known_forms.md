# 布局走线"已知形态"清单（豁免判定与依据汇总）

更新：2026-09-30（R0–R20 迭代轮收尾）。

本文档汇总布局/走线验收中被判定为**可接受形态**（不判违规、打印记录）
的情形、判定位置与依据。全部豁免都是**精确打印、非静默**。

## 1. 水平行线 × 竖放元件文字 = 软冲突

- 判定：`ads_ops.text_wire_conflict_level(elem_angle, a, b)`（唯一事实
  来源，R4 收敛；返回 "soft"/"hard"）。
- 形态：行线从竖放 R/C/L 的参数文字间穿行。手工参考图
  （CE_FM_Amp 的 R1/R2）即此画法，逐行避让在密集放大器里无解。
- 引用方：7.5 步避让（`_hard_seg_hit`）、iterate_ml_sym_metrics、
  fuzz_layout、test_auto_layout、test_ce_amp_acceptance。

## 2. 竖线 × 竖放元件文字 = 已知形态（警告级）

- 形态：分叉元件（对称一分二的 ML1）文字左移 -0.85 后，其保守
  文字区（宽 2.2 格）右缘仍被本组下拉竖线擦过。实测无论左右移都
  躲不开（左压端口文字、右撞隔离电阻走廊、上移压上臂文字）。
- 依据：ml_sym_final.png 渲染验收通过——线擦的是文字区右缘空白带，
  实际字形不相交。zone 模型按 bbox 铺满所致。
- 彻底消除路径（未做）：按渲染字形（词语级 bbox）建模文字区。

## 3. VAR 注释件 × 竖放文字 = 已知形态

- 形态：VAR1 定格高位（多变量高度公式对 1 变量也抬到 row_max+0.8），
  其保守 zone 下缘与输入行竖放文字假重叠 ≤0.75 格。
- 依据：同上，两侧 zone 均按 bbox 铺满、字形不相交。

## 4. 支线耦合器环形拓扑 = 已知问题 ≤1 项

- 形态：TLv2.2→P2.1 的规划线与 TLv2 自身竖放文字区擦过（软形态）。
  2026-09-30 R13 后由 4 项降至 1 项（罚分选优兜底 + 贴边判定限定
  非引脚符号 + 穿自身引脚=合法搭接豁免 三项通用修复的副产物）。
- 在线行为：build_schematic 的在线 _route_clear 会拒绝坏路径并在
  真几何上重寻——该拓扑实机建图 0 问题（第 9 轮实机验证记录）。
