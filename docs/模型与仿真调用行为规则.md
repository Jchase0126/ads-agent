# 模型与仿真调用行为规则

更新：2026-10-31。适用于所有厂商模型包与仿真调用，不限于村田。

规则唯一维护源：`backend/tools.py:SIMULATION_CALL_RULES`。后端系统提示词从该源加载；适用工具的 description 从该源追加，覆盖模型导入/检查、建图/放置、Python、仿真、数据读取、模型验证、发布与优化。下文为同步的人类阅读版本。

【按包验证模型依赖】挂库可见、DEFINE/ASSIGN、原生列表打开均不等于可仿真。逐包核查原厂 Include、encode.net/models.net、#uselib/#load、ADSlibconfig、编码 .library、AEL/Verilog-A 与数据文件；确认各路径属于当前工作区对应包且文件存在。先读当前设计与实际生成网表，不能把历史失败记录当作当前状态。优先使用包内真实的原厂 Include，已有有效入口不得重复添加；逐包递归核对 include 与编码名称映射，不能只验证其中一个包。缺少 DESIGNKIT 注册本身不是失败根因的充分证据，按包要求和实际网表判断；不要修改全局 Favorite/ADSlibconfig 或跨工作区借用映射来掩盖依赖问题。

【仿真启动与错误分层】3221225781/0xC0000135 表示 DLL 加载失败，先查启动环境与 DLL 搜索路径，不能直接归因于缺 include；undefined model/编码库不可解析再查模型依赖。重写 SDK _execute 时必须继承 SDK self._env 的副本，再合并显式 env、extra_env 与本次工作区映射，保留 SDK PATH/HPEESOF_DIR 等设置及 Python/Qt 环境清理；extra_env 不是完整环境。仅对子进程注入映射，不污染宿主环境。修复后经标准 run_simulation 重跑并读取本次日志，不用旧数据集宣称修复成功。

【参数按实际 API】先查元件参数定义、复合类型及方法签名，再赋值；TypeError 后根据签名修正，不能反复猜参数。ads_simulation:NetlistInclude 的相关参数是IncludePath、IncludeFiles、UsePreprocessor，不是 File；IncludePath 是复合类型，需按实际 API 传字符串序列，不能当普通字符串赋值。已有原厂 Include 时优先复用其真实入口，禁止为绕过错误偷偷换成通用 RLC/S 参数器件。

【结果证据】进程退出成功不等于仿真验证通过；必须确认本次 status、日志、新生成的 .ds，并实际读取目标频段、频点数、曲线与有限数值，保存网表/日志/数据集路径。缺模型、缺映射、无数据集、取消/超时或部分结果不能报完整成功。仿真链路恢复与电路指标达标分别判断；ADS 仿真数据不得称为硬件实测。依赖指纹 incomplete 需如实保留，并与仿真加载失败区分，不得改写成 complete。
