# ADS Agent

在 Keysight PathWave ADS 内运行的 AI 助手插件：聊天、原理图自动建图、仿真、射频审查和设计指标评估。

[下载安装包](https://github.com/Jchase0126/ads-agent/releases) · [安装说明](docs/安装说明.md) · [更新记录](CHANGELOG.md) · [开发与发布](docs/版本迭代与发布.md)

> 支持范围：Windows x64。**ADS 2027 为已实机验收基线；ADS 2024–2026 为
> 实验性适配（已完成官方文档研究与离线验证，未实机验证）**，写/建图/仿真
> 需按版本显式开启。不支持 32 位 Windows。详见
> [兼容性矩阵](docs/兼容性矩阵.md) 与 [版本证据报告](docs/版本证据报告.md)。
> 当前提供 ZIP + BAT 安装入口；EXE/MSI 图形安装程序和插件内自动更新尚未实现。

## 安装

1. 从 Releases 下载最新的 `ADSAgent-<版本>.zip` 并完整解压。
2. 运行 `安装 ADS Agent.bat`。ADS 位于需要提升权限的目录时，按安装说明操作。
3. 重启 ADS，在右侧面板的设置中填写 API 地址、密钥并选择模型。

需要自行安装并授权的 ADS（2024–2027；2024–2026 为实验性适配）。插件使用
ADS 自带的 Python 与 Keysight API，不捆绑 ADS 软件；正常运行不要求另装这些
组件。Qt 绑定跟随宿主版本（2026+ 为 PySide6，2024/2025 为 PySide2）。
GitHub 自动提供的 `Source code` ZIP 是开发源码，安装请使用 `ADSAgent-<版本>.zip`。

升级时关闭 ADS，解压新版本并运行安装入口。用户配置、会话、设计任务与日志保存在 `%LOCALAPPDATA%\ADSAgent`，升级和默认卸载保留这些数据。

## 功能

- 在 ADS 内聊天，配置 OpenAI 兼容 API 和模型。
- 读取工作区、设计、变量，修改参数并检查保存结果。
- 构建原理图、自动布局及网表连接等价检查。
- 上传 SPICE 导出的原理图网表（.cir/.sp/.net/.spice），解析为带源行号的 Circuit IR，供 Agent 审阅拓扑并映射到 ADS 建图；原始 AD/嘉立创专有文件当前需先由源软件导出 SPICE 网表。
- 运行仿真、读取真实数据集、导出曲线。
- 从真实数据确定性计算设计指标，生成可恢复的结果页。
- 射频及 Layout 审查，检测几何或连接问题。
- 射频设计前输出本电路的详细实施提示词，并要求逐个解释 L/R/C 功能、FET 接法与偏置依据，在明确硬约束和模型能力后再设计或优化。
- 上传原厂模型 ZIP 并在确认后导入；模型库备份到共享 `libraries` 文件夹（可在设置 `[models] library_root` 指定绝对目录），可从其他工作区检索并导入。
- 在聊天中上传 PDF 数据手册；原 PDF 按 SHA-256 存档，提取文本后随本轮对话发送，扫描件和无法识别字体会明确提示。
- 按手册 ID 查询完整的已提取文本，保存带原文证据和 SI 单位的参数记录；基础 R/L/C 可生成新 cell 的等效测试电路方案。
- PDF 建模产物可发布到器件模型库（`libraries/devices/`）：原子发布、内容指纹去重、不可变版本；后续按型号检索、导入当前工作区并生成可放置元件（子电路 + 层次引脚 + symbol 视图）。未验证模型只能标为 candidate。详见 [数据手册建模说明](docs/数据手册建模说明.md) 与 [器件模型库阶段推进记录](docs/器件模型库阶段推进记录_2026-10-19.md)。
- 在聊天中按厂商型号搜索模型，查看模型信息并验证 ADS 挂接结果。
- RF 计算器窗口（`Tools ▸ ADS Agent ▸ RF 计算器…`）：版式
  版式参考网上资源绘制（黄底计算页/白底偏置页/NoiseCalc 栅格页
  + Outlook 分组侧栏），含传输线（微带/带状线/同轴/双线/线过地板/CPW/板线）、
  级联噪声、混频器杂散、互调、BJT 固定/分压偏置、FET 自偏/分压偏置、放大器
  效率、反射工具、RFIC 电压/电流偏置、大/小信号检波器、S 参数（Smith 图）、
  集总元件巴伦、器件热设计、SPCS、标准值/工程常数/复数运算共 29 页。
  引擎 `backend/rfcalc.py` 纯标准库、SI 单位、公式出处见源码；版式与功能
  参考网上资源，公式均出自公开文献（无任何代码派生），
  数值对比见 [RF 计算器与对拍清单](docs/RF计算器与对拍清单.md)。
- 保存项目会话；本机服务采用随机令牌和实例身份校验。
- **长计算不再卡界面（`run_compute`）**：数值优化、曲线拟合、大规模参数
  扫描/搜索和纯数据文件处理由 Agent 放进**后端的独立计算子进程**执行，
  不占 ADS 主线程；长计算期间界面保持响应，作业可查状态、可取消、可超时
  回收。`run_python` 仍然保留，但只用于短 ADS 对象操作 —— 它在 ADS 主线程
  同步执行且无法安全中断，长计算会把界面冻结到脚本结束。

例如：读取当前设计的 VAR 变量；修改偏置电阻并仿真 S 参数；评估 2.3–2.5 GHz 内增益和 S11。
LLM 提供设计与指标定义，实测值和判定由数据评估代码计算。

## 长计算、停止与超时

三种执行位置，分工是硬边界，不是建议：

| 位置 | 用于 | 能否中断 |
| --- | --- | --- |
| ADS 主线程（`run_python` / 建图 / 仿真提交） | ADS 对象读写等短操作 | 不能中断；已在跑就等它收尾 |
| 独立计算子进程（`run_compute`） | NumPy/SciPy 优化、拟合、搜索、数据文件处理 | 能：协作取消 → 宽限 → 结束进程树 |
| 仿真后台线程（`run_simulation`） | ADS 仿真 | **仿真进程可取消**（见下）；网表生成阶段不可中断 |

- **停止按钮**：面板用本轮 `turn_id` 调 `/chat/cancel`，后端立刻不再发起新的
  模型请求和工具派发，把取消传播到本轮登记的每个作业（`job_id` 在派发**前**
  登记）：排队中的直接取消（处理器不会执行）、计算子进程请求停止并在宽限期后
  回收、ADS 侧作业经工具服务 `/cancel` 请求取消。面板同时关掉正在读的 SSE
  连接，读取线程立刻退出，不再等 keepalive 或 1800s 的 socket 超时。
- **如实两阶段**：界面先显示"已请求取消"，作业真的退出后才显示已停止。
  "HTTP 请求结束"不等于"执行结束"。
- **仿真进程能真的停**：`hpeesofsim` 是本插件自己 `Popen` 的子进程，所以取消与
  `sim_timeout` 都能终止它（先 `terminate`，宽限 `sim_cancel_grace_s` 内没退才
  `taskkill /T /F` **仅本插件自己的 pid 树**，绝不按进程名批量杀）。被自己终止
  的仿真返回 `status=cancelled|timed_out` + `partial=true`，不会谎报成功。
  注意 `keysight.edatoolbox` 本身**没有** timeout/cancel 参数（底层是同步的
  `subprocess.check_call`），这是插件接管子进程实现的能力；网表生成阶段仍在
  主线程、仍不可中断。
- **超时**：客户端等待超时只结束等待，作业状态仍可查询；执行预算到期由
  计算管理器终止 worker 并标记 `timed_out`。超时或取消后不会自动重做尚未确认
  结束的写入。
- **健康检查**：`/health` 同时给出 HTTP 是否可达、GUI 心跳年龄
  （`gui_heartbeat_age_ms` / `heartbeat_stale`）、排队数、执行中作业、取消中
  或等待回收的作业。心跳陈旧只说明主线程**疑似**阻塞，不等于死锁。
- 进程隔离只用于**资源隔离与可回收性**，不是安全沙箱：计算代码拥有它所在进程
  的全部权限（文件、网络、任意 import），请只运行你信任的代码。

## 架构

```text
ADS 进程（2024–2027，Windows x64）
  ├─ Qt 绑定适配（PySide6 / PySide2，qtcompat 自动选择）
  ├─ 聊天面板 + 兼容层（版本识别 / 能力检测 / 工具门禁）
  └─ 本机工具服务 → ADS 数据库 / 建图 / 仿真 / 数据集
           ↑
  本机 Python 后端 → LLM API、工具派发、设计指标评估
           └─ run_compute → 独立计算子进程（NumPy/SciPy，可取消、可超时回收）
```

```text
addon/ads_agent/       ADS 插件入口、面板、工具服务和设计操作
backend/              对话循环、接口、路径、实例、指标评估和计算作业管理
  compute_manager.py    计算作业排队 / 取消 / 预算 / 进程树回收
  compute_worker.py     计算子进程运行时（run_compute 的执行体）
tests/                离线回归测试与电路用例
release_manifest.py   运行文件打包白名单
install_addon.py      安装、部署、注册、升级和卸载
config.example.ini    不带密钥的配置模板
tools/build_release.py 可重复构建 ZIP
.github/workflows/    离线 CI 和版本标签发布
docs/                 使用、技术和版本发布说明
```

## 开发与验证

```powershell
python -m pip install PySide6==6.8.3
python tests/run_tests.py
python tools/build_release.py
```

Python 3.12 和 3.14 用于 GitHub 离线 CI，UI 测试使用 offscreen 模式。
测试构建不需要 ADS，但真实建图、仿真和插件生命周期需要本地 ADS 实机验收。
新增运行模块需同步 `release_manifest.py`；不要提交真实配置、会话、日志或仿真产物。

## 版本发布

修改 `backend/paths.py` 中的 `PLUGIN_VERSION`，更新 `CHANGELOG.md` 和 `docs/releases/<版本>.md`。
合入 `master` 后推送对应 `v<版本>` 标签，Actions 自动测试并构建 ZIP、SHA-256 校验文件和草稿 Release。
完成实机验收、核对附件后发布草稿。详见 [版本迭代与发布](docs/版本迭代与发布.md)。

工程发布流程已经提供；自动更新插件需要后续另行实现。
