ADS Agent —— 第三方依赖与许可证说明

================================================================================
一、本插件自己
================================================================================

ADS Agent 是用户自行开发并使用的插件，源码随分发包提供。
本分发包**不包含** ADS 或 Keysight 的任何可执行文件、库或文档。

**没有附带开源许可证声明**：本项目的许可证归属由作者决定。本文件不替作者
做出开源授权决定，也不声称本插件属于任何开源许可证。如果作者尚未指定，
接收者应视为"保留所有权利"，按作者的要求使用。

================================================================================
二、运行时依赖
================================================================================

本插件的后端（backend/）**只使用 Python 标准库**，不安装任何 pip 包：

    http.server, threading, json, urllib, configparser, logging,
    logging.handlers, xml.etree.ElementTree, secrets, hmac, ctypes, winreg 等

ADS 端插件（addon/ads_agent/）在 ADS 进程内运行，依赖以下**由 ADS 提供**的组件：

    * Python 解释器        <ADS安装目录>\tools\python\python.exe
    * PySide6（Qt for Python）  ADS 自带，用于聊天面板与结果页
    * keysight.ads.de       ADS 的设计环境数据库 API（官方 addon 契约）
    * keysight.ads.dataset  ADS 仿真数据集读取
    * keysight.edatoolbox   ADS 的网表仿真器

这些组件**不属于本分发包**，其使用受 Keysight PathWave ADS 2027 的最终用户许可
协议（EULA）约束。本插件不修改、不替换、不再分发其中任何部分。

因此：**本分发包没有再分发任何需要额外授权的软件**。

================================================================================
三、数据如何保存
================================================================================

* 用户数据写在 %LOCALAPPDATA%\ADSAgent 下（配置、会话、设计任务、日志）。
* API Key 与回环令牌保存在该目录的 config.ini 里。
  分发包**不含** config.ini，只含不带密钥的 config.example.ini 模板。
* 仿真产物（网表与 .ds 数据集）写在用户的 ADS 工作区
  <工作区>/ads_agent_sim/ 下，路径由用户的工作区决定，不在本包内。

================================================================================
四、第三方代码与素材
================================================================================

本插件未复制任何第三方项目的源代码或二进制（无 vendored 依赖）。
ADS 端的 API 用法参考了 ADS 2027 自带的示例代码与官方文档
（例如 doc/python/dds/examples/app/ex_addon.py），属于参考其**用法**，
未复制其代码。

================================================================================
五、构建打包时的依赖（不随分发包发布）
================================================================================

打包脚本 tools/build_release.py 只使用 Python 标准库
（zipfile / py_compile / shutil / hashlib），不安装任何包。

================================================================================
六、核对方法
================================================================================

分发包 ZIP 内有一份「发布清单.txt」，列出了包内每个文件的路径、大小与
SHA-256 前 16 位。要核对收到的包有没有被改过，重新生成一次清单对一遍即可：

    python tools/build_release.py
